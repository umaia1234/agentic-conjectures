# OEIS A396093: 두 홀짝성 추측

## 결론

[OEIS A396093](https://oeis.org/A396093)의 생성함수를
\(A(x)=\sum_{n\geq 0}a(n)x^n\)이라 하자. 이 생성함수는

\[
A(x)=B(B(B(x))), \qquad B(x)=\frac{x}{(1-x)^2}
\]

로 정의된다. 항목에 실린 두 홀짝성 추측은 모두 **참**이다.

1. 모든 \(n\geq 1\)에 대해 \(a(2n)\)은 짝수이다.
2. \(n\geq 1\)일 때, \(a(2n-1)\)이 짝수일 필요충분조건은 어떤
   \(k\geq 1\)에 대해 \(n=5k-2\)인 것이다.

Lean 증명은 더 강한 완전 분류

\[
a(n)\text{이 짝수}
\quad\Longleftrightarrow\quad
n\text{이 짝수이거나 }n\equiv 5\pmod {10}
\]

를 보인다.

## 증명

OEIS 항목은 다음 유리 생성함수를 제시한다.

\[
A(x)=
\frac{x(1-x)^2(1-3x+x^2)^2}
     {(1-7x+13x^2-7x^3+x^4)^2}.
\]

이를 \(\mathbf F_2[[x]]\)에서 줄이면 분자와 분모는

\[
N(x)=x(1+x^6), \qquad
D(x)=1+x^2+x^4+x^6+x^8
\]

이 된다. 또한

\[
(1+x^2)D(x)=1+x^{10}
\]

이다. 여기서 모든 분모의 상수항이 1이므로 형식적 나눗셈이 가능하고,

\[
A(x)=\frac{x(1+x^2)(1+x^6)}{1+x^{10}}
    =(x+x^3+x^7+x^9)\sum_{j\geq 0}x^{10j}
    \quad\text{in }\mathbf F_2[[x]]
\]

를 얻는다. 따라서 \(a(n)\)이 홀수일 필요충분조건은
\(n\equiv 1,3,7,9\pmod {10}\)이다. 모든 짝수 인덱스가 여기서 제외된다.
홀수 인덱스 \(2n-1\)에서는 짝수일 조건이
\(2n-1\equiv 5\pmod {10}\), 즉 \(n\equiv 3\pmod 5\)이고, 이는 정확히
\(k\geq 1\)에 대한 \(n=5k-2\)와 같다.

## Lean 형식화와 원문 일치성

[`AgenticConjectures/OeisA396093.lean`](../../AgenticConjectures/OeisA396093.lean)은
항목의 초기값 \(a(0),\ldots,a(7)\)과 공개된 8차 점화식을
\(\mathbb Z\) 위에서 그대로 옮긴다. 점화식을 2로 줄이면

\[
a(n+8)\equiv a(n+6)+a(n+4)+a(n+2)+a(n)\pmod 2
\]

가 된다. 이 식을 \(n\)과 \(n+2\)에서 사용하면
\(a(n+10)\equiv a(n)\pmod 2\)를 얻는다. 첫 열 개 항에서 시작하는 강한
귀납법으로 위의 완전 분류와 두 원문 명제를 증명한다.

OEIS 오프셋은 0이고 항목은 \(a(0)=0\)을 명시적으로 앞에 붙인다. Lean
정의도 동일하다. 정수값 점화식은 \(\mathbb Z\)로 표현하므로 자연수 뺄셈의
절단이 개입하지 않는다. 첫 정리는 원문의 \(n\geq 1\)보다 강하게 \(n=0\)도
포함한다. \(n,k\geq 1\) 조건 때문에 자연수 식 `2*n - 1`과
`5*k - 2`는 보통의 정수식과 같은 뜻이다. 고정된 Formal Conjectures
원문에는 A396093 스냅샷이 없었으므로, 형식 명제는 공식 OEIS 항목과 직접
대조했다.

공리 감사를 받는 정리는 다음과 같다.

- `AgenticConjectures.OeisA396093.even_a_iff`;
- `AgenticConjectures.OeisA396093.even_index_even`;
- `AgenticConjectures.OeisA396093.odd_index_even_iff`.

세 정리 모두 `sorry`, 추가 공리, `native_decide` 없이 컴파일된다.

## 독립 인증서

[`a396093_certificate.py`](a396093_certificate.py)는 Python 표준
라이브러리만 사용하며 Lean 점화식 증명과 독립적으로 생성함수 경로를 따른다.

- \(B(x)=x/(1-x)^2\)를 정확한 다항식 산술로 세 번 합성한다.
- 표시된 유리함수와 점화식 계수
  \((14,-75,196,-269,196,-75,14,-1)\)을 복원한다.
- 항목에 표시된 27개 항과 독립적인 공개 이중합 공식을 \(n=30\)까지
  확인한다.
- 무한한 주기 10 홀짝성 패턴을 증명하는 \(\mathbf F_2\) 다항식 항등식을
  교차곱으로 확인한다.
- 정확한 점화식 항 501개로 회귀 검사를 한다.

저장소 루트에서 실행한다.

```bash
python3 problems/oeis-a396093/a396093_certificate.py
lake build AgenticConjectures.OeisA396093
```

2026-08-12 검증 머신에서 인증서는 약 0.04초가 걸렸다. 설치된 mathlib
캐시를 공유하는 격리된 연결 작업트리에서 첫 직접 Lean 컴파일은 약 44초가
걸렸다.

## 출처 이력, 선행 결과 검색, 외부 제출 상태

[항목 이력](https://oeis.org/history?seq=A396093)을 2026-08-12에 확인했다.
Paul D. Hanna가 2026년 5월 수열을 작성했고, 두 추측은 5월 19일 이력
revision 3에서 추가되었다. 영항과 오프셋 0은 5월 20일에 추가되었고 상수
점화식도 같은 날 추가되었다. 이력의 최신 내용 revision은 5월 28일의
revision 31이었으며, 현재 항목은 여전히 두 명제를 추측으로 표시했다.

수열 식별자, 정확한 추측 문구, 유리함수 분모, 초기항으로 검색한 결과 OEIS
자료와 프로그램 구현은 찾았지만 OEIS, arXiv, GitHub 또는 공개 웹에서 증명이나
중복 결과는 찾지 못했다. 더 오래된 [OEIS A166482](https://oeis.org/A166482)의
생성함수도 같은 홀짝성 패턴으로 가는 짧은 경로를 주지만, 그곳에서도 공개
홀짝성 증명은 찾지 못했다. 이 부정적 검색 결과는 신규성의 근거가 아니다.
결과는 검토되지 않았고 신규성을 주장하지 않으며, OEIS 또는 다른 외부 채널에
아무것도 제출하지 않았다.
