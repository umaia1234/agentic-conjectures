# OEIS A384162: n = 2 반례

## 결론

[OEIS A384162](https://oeis.org/A384162)의 추측식

\[
a(n)=n\,A342168(n-1)
\]

은 **이미 \(n=2\)에서 거짓**입니다. A384162 항목의 수열 데이터와
표시된 단어 6개의 직접 나열은 모두 \(a(2)=6\)을 줍니다. 한편
[OEIS A342168](https://oeis.org/A342168)은

\[
A342168(m)=U_m\!\left(\frac{m+3}{2}\right)
\]

로 정의되므로 \(A342168(1)=U_1(2)=4\)입니다. 따라서 추측식의 우변은

\[
2\,A342168(1)=2\cdot4=8\ne6=a(2)
\]

입니다.

## 출처와 명제의 충실성

2026-08-12에 공식 항목을 확인했습니다. A384162은 revision 8
(최종 수정 2025-05-27), offset 1이며, 위 식을 추측으로 표시합니다.
A342168은 revision 32(최종 수정 2024-06-28), offset 0입니다. 따라서
`n-1`은 A342168의 문자 그대로의 인덱스이며, 반례에 숨은 offset 변환이나
경계값 문제는 없습니다.

Lean 모듈은 같은 공식 항목에 실린 다른 두 공식을 사용합니다.
A384162의 유리 생성함수는

\[
\frac{nx}{1-x(1-x+n)}=\frac{nx}{1-(n+1)x+x^2}
\]

이므로, 계수는 \(c_0=0\), \(c_1=n\),
\(c_{k+2}=(n+1)c_{k+1}-c_k\)를 만족합니다. A342168은 게시된 유한
이항합 공식을 Lean으로 정의했습니다. 첫 점화식은 정수 계수를 써서
자연수 빼기의 절단 의미가 개입하지 않습니다. Python 인증서는 의도적으로
다른 정의를 따라 표시된 단어를 전수 나열하고 Chebyshev 점화식을 계산합니다.

이 반례에 필요한 내용은 아니지만, 대수 계산은 수열 번호 한 자리의 오타일
가능성도 가리킵니다. 계수를 추출하면

\[
a(n)=n\,U_{n-1}\!\left(\frac{n+1}{2}\right)
\]

을 얻습니다. A342168이 아니라
[OEIS A342167](https://oeis.org/A342167)이
\(A342167(m)=U_m((m+2)/2)\)로 정의됩니다. 따라서 \(m=n-1\)을 대입하면
\(n\,A342167(n-1)\)이라는 일치하는 식을 얻습니다.

## 기계 검증

[`a384162_certificate.py`](a384162_certificate.py)는 Python 표준 라이브러리만 사용합니다.
각 값을 독립적인 두 방법으로 계산합니다.

- \(A384162(2)=6\): 표시된 단어의 전수 나열과 유리 생성함수 점화식.
- \(A342168(1)=4\): Chebyshev 점화식과 유한 이항합.

저장소 루트에서 다음을 실행합니다.

```bash
python3 problems/oeis-a384162/a384162_certificate.py
lake build AgenticConjectures.OeisA384162
```

2026-08-12 검증 머신에서 인증서는 0.01초가 걸렸고, mathlib 캐시가 이미
설치된 상태의 첫 대상 Lean 빌드는 5.5초가 걸렸습니다.

Lean 4 정리
`AgenticConjectures.OeisA384162.oeis_a384162_conjecture_false`는
`sorry`, 추가 공리, `native_decide` 없이 보편 공식의 부정을 증명합니다.

## 선행 결과 검색과 외부 제출 상태

2026-08-12에 두 수열 식별자와 정확한 공식으로 검색했습니다. 공식 OEIS
데이터와 프로그램 미러는 발견했지만, OEIS 항목·공개 웹·arXiv·GitHub
코드·GitHub 이슈에서 공개된 정정, 증명, 반례는 찾지 못했습니다. 이런
부정적 검색 결과는 신규성의 근거가 아닙니다. 결과는 아직 검토되지 않았고,
신규성을 주장하지 않으며, OEIS 또는 다른 외부 채널에 아무것도 제출하지 않았습니다.
