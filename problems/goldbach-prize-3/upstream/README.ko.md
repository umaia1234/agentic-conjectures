원문은 요구하는 표현을 다음 문구로 도입한다.

> “It is required to prove that this set can be expressed as”

그리고 (S=\{f(x):g(x)\in\{n_2a_2+\cdots+n_ka_k:a_i\in I_i\}\})를
제시한다. (f,g)에는 산술, 나눗셈, 나머지, 올림·내림, 유한한 경우 구분을
허용하며, 각 (I_i)에는 양의 정수의 유한 부분집합이라는 조건만 둔다.
이 파일은 명제 충실성 대조에 사용한 웹 문구의 메타데이터를 기록하며, 공식
페이지가 최종 원문이다.
