# OEIS A000224 추측 공격 기록

확인 기준일: 2026-08-11.

`R(n)`을 modulo `n`에서 서로 다른 제곱잉여(0 포함)의 수라고 하겠습니다.
[OEIS A000224](https://oeis.org/A000224)는 다음을 추측합니다.

> `n>1`일 때 `R(n)(R(n)-1) | n^2-1`인 것과 `n`이 홀수 소수인 것은
> 동치이다.

OEIS에는 `10^8`까지 확인되었다고 기록되어 있습니다. 아래 결과는 전체
추측의 증명이 아니라, 합성수 방향에서 얻은 엄밀한 부분정리와 추가 계산
탐색입니다.

## 이번에 증명한 범위

다음 세 부류에는 합성수 반례가 없습니다.

1. 모든 짝수 `n`;
2. 모든 홀수 소수거듭제곱 `p^e`, `e>=2`;
3. 서로 다른 두 홀수 소수의 곱 `p*q`.

따라서 반례가 있다면 홀수이고, 서로 다른 소인수를 적어도 둘 가지며,
소인수의 중복도를 센 `Omega(n)`은 적어도 3입니다. 세 번째 항목은 작은
유한 계산을 마지막 단계로 사용하는 computer-assisted proof입니다.

## 준비식

`R`은 multiplicative이고, 홀수 소수 `p`에 대해

```text
R(p^e) = floor(p^(e+1)/(2p+2)) + 1.
```

더 구체적으로 `r=R(p^e)`라 하면

```text
2(p+1)r = p^(e+1) + 2p+1    (e odd),
2(p+1)r = p^(e+1) + p+2     (e even).
```

나눗셈 조건이 성립하면 당연히

```text
gcd(n, R(n)(R(n)-1)) = 1.                         (1)
```

반대 방향은 즉시 확인됩니다. 홀수 소수 `p`이면 `R(p)=(p+1)/2`이므로

```text
R(p)(R(p)-1) = (p^2-1)/4.
```

따라서 몫은 정확히 4입니다.

## 짝수와 소수거듭제곱

`n`이 짝수이면 `n^2-1`은 홀수인 반면, 연속한 두 정수의 곱
`R(R-1)`은 짝수이므로 즉시 불가능합니다.

이제 `n=p^e`, `p` 홀수, `e>=2`라 하겠습니다.

- `e`가 짝수이면 위 식을 modulo `p`로 줄여 `r == 1 (mod p)`를 얻습니다.
  따라서 `p | r-1`인데 `p`는 `p^(2e)-1`을 나눌 수 없어 (1)에 모순입니다.
- `e`가 홀수이면

  ```text
  r   = (X+2p+1)/(2(p+1)),
  r-1 = (X-1)/(2(p+1)),       X=p^(e+1).
  ```

  직접 비교하면 다음의 열린 구간을 얻습니다.

  ```text
  4r(r-1) < p^(2e)-1 < 5r(r-1),       p>=11;
  5r(r-1) < p^(2e)-1 < 6r(r-1),       p=5,7;
  7r(r-1) < p^(2e)-1 < 8r(r-1),       p=3, e>=5.
  ```

  남은 `(p,e)=(3,3)`은 `r=11`이고
  `6*110 < 27^2-1 < 7*110`입니다. 어느 경우에도 비율이 정수가 아닙니다.

비교식은 양의 수 `4p^2(p+1)^2`를 곱하면 단순한 이차식의 부호 확인으로
바뀝니다. 예를 들어 4배와의 차이는

```text
4(X-p^2)(2Xp+X+p^2) > 0,
```

이고, 5배의 최고차항 계수는 `-p^2+8p+4<0` (`p>=11`)입니다. `p=3,5,7`은
위에 적은 경계값을 대입하면 됩니다.

## 서로 다른 두 소수의 곱

`n=pq`, `3<=p<q`이고

```text
a=(p+1)/2,  b=(q+1)/2,  R=ab
```

라 두겠습니다. 나눗셈이 성립한다고 하고

```text
K=(n^2-1)/(R(R-1))
```

라 두면 `K`는 양의 정수입니다.

먼저 직접 전개하면

```text
16R(R-1) - (n^2-1)
 = 2p^2q+p^2+2pq^2-2p+q^2-2q-2 > 0,
```

이므로 `K<=15`입니다. 한편 `n^2>R`이므로

```text
K > (n/R)^2
  = ((2-1/a)(2-1/b))^2
  > (2-1/a)^4.
```

`a>=32`이면 우변은 `(63/32)^4>15`입니다
(`63^4-15*32^4=24321`). 따라서 반드시 `a<=31`, 즉 `p<=61`입니다.

또 `R | n^2-1`이고 `q == -1 (mod b)`이므로

```text
b | p^2-1 = 4a(a-1).                               (2)
```

이제 `p<=61`인 소수와 (2)의 약수만 확인하면 됩니다.
`semiprime_certificate.py`는 외부 라이브러리 없이 이 정확한 유한 집합을
열거합니다. 조건 (2)와 소수 조건으로 얻는 원시 후보는 117쌍이고, 이 중
`R | n^2-1`까지 통과하는 것은 22쌍뿐입니다. 그 모든 경우
`(n^2-1) mod (R-1)`가 0이 아님을 확인합니다.

재현 명령:

```bash
python problems/oeis-a000224/semiprime_certificate.py \
  --output problems/oeis-a000224/semiprime_result.json
```

## 모든 잠재 반례가 만족해야 하는 추가 local 조건

`p^e || n`, `m=n/p^e`, `r_p=R(p^e)`라 하고

```text
c_p = 2p+1  (e odd),
c_p = p+2   (e even)
```

라 두겠습니다. `R(n) | n^2-1`이라면 `r_p | n^2-1`입니다. 위 준비식에서
`p^(e+1) == -c_p (mod r_p)`이고 `gcd(p,r_p)=1`이므로

```text
r_p | m^2*c_p^2 - p^2.                             (3)
```

우변은 양수입니다. 특히

```text
p^(e+1) < 2(p+1)m^2*c_p^2,
```

이므로 한 소수거듭제곱이 cofactor에 비해 지나치게 큰 후보는 자동 배제됩니다.
이 조건은 남은 `p^e q^f` 및 다소인수 경우의 branch-and-bound에 유용합니다.

## generalized-Pell 탐색

나눗셈 몫 `K`가 정수라면 `X=2n`, `Y=2R-1`에 대해 정확히

```text
X^2-KY^2 = 4-K                                      (4)
```

입니다. `pell_quotient_scan.py`는 `K<=375`, `n<=10^18`에서 (4)의 모든
CAS 생성 후보를 열거한 뒤 실제 소인수분해로 `R(n)`을 다시 계산합니다.
이는 선형 범위 스캔이 아니라 Pell orbit 스캔입니다.

홀수 `n`의 서로 다른 소인수 수를 `omega(n)=s`라 하면 각 local factor에서

```text
p^e/R(p^e) < 2(p+1)/p <= 8/3.
```

따라서 `s<=3`일 때 잠재 몫은 `K<=375`입니다. 그러므로 이 탐색은
`n<=10^18`이고 `omega(n)<=3`인 모든 미해결 형태도 포함합니다. 다만 Pell
seed의 완전성은 SymPy의 exact `diop_DN` 구현에 의존하므로, 이 부분은
전체 추측의 독립 형식증명이 아니라 재현 가능한 CAS-assisted 계산으로
분류합니다.

```bash
python problems/oeis-a000224/pell_quotient_scan.py \
  --max-k 375 --max-n 1000000000000000000 \
  --output problems/oeis-a000224/pell_result.json
```

`K=1`은 `(X-Y)(X+Y)=3`에서 `n=1`만 줍니다. `K=4`는 별도 증명으로
처리합니다. (4)가 `n=2R-1`을 강제합니다. 홀수 소수거듭제곱 `x=p^e`에는
`R(x)<=(x+1)/2`이고 등호는 `e=1`일 때만 성립합니다. 서로소인 홀수
`u,v>1`에 대해서는

```text
R(uv)=R(u)R(v) <= (u+1)(v+1)/4 < (uv+1)/2,
```

이므로 홀수 `n>1`에 대해 `R(n)=(n+1)/2`인 경우는 정확히 홀수 소수뿐입니다.

## 한계

- 일반적인 `p^e q^f` 및 서로 다른 소인수가 네 개 이상인 경우는 아직
  증명하지 못했습니다.
- Pell 탐색의 `K,n` 경계 밖도 남아 있습니다.
- 따라서 OEIS 추측 자체를 해결했다고 주장하지 않습니다.
