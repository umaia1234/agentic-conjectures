# 유한 반지름 검증의 수학적 세부 사항

## 확인한 유한 명제

\(1\le|V(G)|\le7\)인 모든 유한 단순 그래프 \(G\)에 대해
\(\mathcal C_3(G)\)와 \(\mathcal C_4(G)\)가 모두 연결되어 있으면 다음이
성립한다.

\[
  \operatorname{rad}\mathcal C_3(G)
  \ge
  \operatorname{rad}\mathcal C_4(G).
\]

프로그램은 이 범위의 각 그래프 동형류에서 대표 하나를 검사한다. 그래프
동형은 재색칠 그래프의 동형을 유도하므로 연결성과 반지름은 대표의 선택에
의존하지 않는다.

## 색 치환 환원

\(k\)개 색 이름의 대칭군은 올바른 \(k\)-색칠에 작용한다. 재색칠 경로의
모든 상태에 하나의 전역 색 치환을 적용하면 \(\mathcal C_k(G)\)의 자기동형을
얻는다. 따라서 같은 궤도에 속하는 색칠은 이심률이 같다.

각 궤도에는 제한 성장 형태의 대표가 정확히 하나 있다. 꼭짓점 레이블 순서로
색을 읽으며 처음 나타난 색을 0으로 바꾸고, 이후 처음 나타나는 색마다 다음
사용하지 않은 정수로 바꾸면 된다. 그러므로 제한하지 않은 BFS로 연결성을
확인한 뒤, 반지름을 정의하는 최솟값을 구할 때는 제한 성장 상태에서만 이심률
BFS를 실행해도 충분하다. 두 구현은 서로 다른 상태 표현을 사용하면서 이
환원을 각각 적용한다.

## 비연결 입력 그래프

\(G=G_1\mathbin{\dot\cup}G_2\)이면 두 성분으로의 제한은 다음 표준적인 그래프
동형을 준다.

\[
  \mathcal C_k(G)
  \cong
  \mathcal C_k(G_1)\mathbin{\square}\mathcal C_k(G_2),
\]

여기서 \(\square\)는 그래프의 데카르트 곱이다. 한 번의 재색칠은 꼭짓점 하나,
따라서 성분 색칠 하나만 바꾸므로 인접 관계가 정확히 대응한다. 데카르트 곱은
두 인자가 모두 연결일 때 그리고 그때만 연결이다. 연결된 데카르트 곱에서
거리는 다음처럼 더해진다.

\[
  d((x_1,x_2),(y_1,y_2))=d(x_1,y_1)+d(x_2,y_2).
\]

따라서 이심률이 더해지고 두 좌표에서 독립적으로 최솟값을 취하면 다음을
얻는다.

\[
  \operatorname{rad}(H_1\mathbin{\square}H_2)
  =\operatorname{rad}(H_1)+\operatorname{rad}(H_2).
\]

귀납법으로 유한 개 성분에 대해서도 같은 결론을 얻는다. C++ 구현은 전체 곱을
직접 열거한다. Python 검증기는 꼭짓점 7개까지 성분 공식을 사용하고, 꼭짓점
6개 이하인 모든 입력 그래프에서는 \(k=3\) 결과를, \(k=3\) 재색칠 그래프가
연결된 입력에서는 \(k=4\) 결과도 전체 곱 직접 BFS와 비교한다.

## 완전 탐색과 실패 조건

프로그램이 입력 그래프에 대해 \(k=3\) 또는 \(k=4\)를 검사할 때마다 레이블된
꼭짓점 집합에서 \(k\)-색 팔레트로 가는 모든 함수를 열거하고 정확히 올바른
색칠만 남긴다. 한 색칠에서 꼭짓점 하나의 색을 바꾸어 얻는 모든 올바른 상태를
생성한다.
따라서 구성한 인접 관계는 정확히 \(\mathcal C_k(G)\)의 인접 관계이며, 보통의
BFS가 정확한 거리를 계산한다. 두 프로그램 모두 먼저 \(k=3\)을 검사하며,
\(\mathcal C_3(G)\)가 비연결이면 해당 그래프는 유한 명제의 가정에서 벗어나므로
\(k=4\)를 검사할 필요가 없다.

graph6 데이터의 SHA-256이 다르거나, 중복 또는 잘못된 레코드가 있거나,
차수별 개수가 표준값과 다르거나, 기록된 연결 쌍 개수와 일치하지 않거나,
공통 직접 BFS 범위에서 두 구현이 불일치하거나, 반례가 하나라도 발견되면
인증서는 실패한다. 고정 데이터는 차수 1부터 7까지 각각
\(1,2,4,11,34,156,1044\)개의 비동형 단순 그래프를 포함한다.

남는 외부 신뢰 지점은 NetworkX 3.6.1이 표준 Graph Atlas를 충실히 제공한다는
것이다. `generate_atlas_data.py`는 이 출처를 재현 가능하게 하고 결과 바이트를
고정한다. 검증기는 성공한 유한 탐색을 기록된 범위 밖의 그래프에 대한 근거로
취급하지 않는다.
