# WOWII 그래프 추측 189: 수학적 세부사항

이 문서는 σ ≤ 4 탐색의 바탕이 되는 횡단 집합(transversal) 상한, σ = 4 데이터가 극단적인
그래프에 대해 보여 주는 것, σ = 5를 다룰 수 없는 이유, 그리고 효과가 없었던 접근을 설명한다.
상한의 권위 있는 증명은 Lean 모듈([소스](../../AgenticConjectures/WowiiGraphConjecture189.lean))이고,
이 문서는 그 안내서다. 기호는 [README](README.ko.md)를 따른다. (H)는 가설이고, σ는 두 번째로
작은 차수다.

## 1. 정점 분할

정점 x를 고정한다. v로부터 짝수 거리에 있는 정점들의 집합을 D(v)라 하면, (H) 아래에서
|D(v)| = dist_even(v) ≤ σ + 1이다. x로부터 홀수 거리 3 이상에 있는 정점들의 집합을 O(x)라 하자.
모든 정점은 x로부터 짝수 거리에 있거나, x에 인접하거나, O(x)에 속하므로

  n = dist_even(x) + deg(x) + |O(x)|

이다. 아래에 나오는 n의 상한은 모두 |O(x)|의 상한이다. `card_le_distEven_add_degree`의 상한은
O(x)의 각 정점을, 그 정점을 거리 2에서 보는 D(x) \ {x}의 정점에 대응시킨다. 그러면
|O(x)| ≤ (dist_even(x) − 1)·σ ≤ σ²이고 n ≤ (σ + 1)²이다.

## 2. 횡단 집합 상한

`exists_card_add_mul_self_le`: (H) 아래에서 모든 정점 x에 대해 다음을 만족하는 s ≥ 0이 있다.

  n + s² ≤ dist_even(x) + deg(x) + s·(σ + 1)

즉 |O(x)| ≤ s·(σ + 1 − s)이다.

**증명.** z ∈ O(x)마다 d(x, q(z)) = d(x, z) − 1인 이웃 q(z)를 하나 고정한다. 이 거리는 짝수이고
2 이상이다. 정점 p ≠ x에 대해 d(y, p) = d(x, p) − 1인 x의 이웃 y들의 집합, 곧 x에서 p로 가는
최단 경로 위에 있는 x의 이웃들의 집합을 Dn(p)라 하자. 이 집합은 비어 있지 않다.

1. *y ∈ Dn(q(z))이면 y는 z로부터 짝수 거리에 있다.* 실제로
   d(y, z) ≤ d(y, q(z)) + 1 = d(x, z) − 1이고, y가 x에 인접하므로 d(y, z) ≥ d(x, z) − 1이다.
   따라서 d(y, z) = d(x, z) − 1이고, 이는 짝수다.
2. 모든 z ∈ O(x)에 대해 Dn(q(z))와 만나는 N(x)의 부분집합 가운데 크기가 가장 작은 것을 Y라 하고,
   그 크기를 s라 하자. N(x) 자체가 이런 집합이므로 Y는 존재한다. Y가 최소이므로 각 y ∈ Y에는
   *전용* 정점 z_y ∈ O(x)가 있다. 즉 Dn(q(z_y))에 속하는 Y의 원소는 y뿐이다.
3. *각 y′ ∈ Y에 대해 |D(y′)| ≥ s + |D(y′) ∩ O(x)|이다.* Y의 다른 원소 y를 각각 정점 f(y)로
   보낸다.
   - y가 y′에 인접하지 않으면 f(y) = y로 둔다. 둘 다 x의 이웃이므로 d(y′, y) = 2이다.
   - y가 y′에 인접하면 f(y) = q(z_y)로 둔다. 그러면 d(y′, q(z_y))는
     d(y, q(z_y)) + 1 = d(x, q(z_y)) 이하이고 d(x, q(z_y)) − 1 이상이다. 전용성에 의해
     y′ ∉ Dn(q(z_y))이므로 d(x, q(z_y)) − 1은 아니다. 따라서 d(x, q(z_y))와 같고, 이는
     짝수다.

   각 f(y)는 y′로부터 짝수 거리에 있고, x의 이웃이거나 x로부터 짝수 거리에 있으므로 O(x) 밖에
   있다. f는 단사다. 두 값 q(z_y) = q(z_{y″})가 같으면 y″가 Dn(q(z_y))에 속하게 되어 전용성에
   어긋나고, 값 y는 x로부터 거리가 1인 반면 값 q(z)는 x로부터 거리가 짝수다. 어떤 값도 y′와
   같지 않다. 따라서 D(y′)는 y′, f의 값 s − 1개, D(y′) ∩ O(x)를 포함하고, 이들은 모두 서로
   다르다.
4. (H) 아래에서 |D(y′)| ≤ σ + 1이므로 |D(y′) ∩ O(x)| ≤ σ + 1 − s이다. 1단계에 의해
   y ∈ Y에 대한 집합 D(y) ∩ O(x)들이 O(x)를 덮으므로 |O(x)| ≤ s·(σ + 1 − s)이다. ∎

4s(σ + 1 − s) ≤ (σ + 1)²이므로 `four_mul_card_le`는 모든 x에 대해
4n ≤ 4(σ + 1) + 4·deg(x) + (σ + 1)²을 준다. 차수가 σ인 정점에서는 이것이
`four_mul_card_le_sq`이다.

  n ≤ 2σ + 1 + ⌊(σ + 1)² / 4⌋

σ ≤ 4이면 모든 정점에서 n ≤ deg(x) + 11이다. `search_reduction_four`는 탐색이 쓰는 사실을
모은 것이다. (H)가 성립하고 σ ≤ 4이면 n ≤ 15이고, 최소 차수는 n − 11 이상이며, 모든 정점으로부터
거리 2에 있는 정점은 넷 이하이고, 차수가 4 이하인 정점이 둘 이상 있다.

| σ | 이전 상한 (σ + 1)² | 새 상한 2σ + 1 + ⌊(σ + 1)²/4⌋ | 가장 큰 (H) 그래프 |
| ---: | ---: | ---: | ---: |
| 1 | 4 | 4 | 4 |
| 2 | 9 | 7 | 7 |
| 3 | 16 | 11 | 10 |
| 4 | 25 | 15 | 13 |
| 5 | 36 | 20 | 알 수 없음, 11 이상 |

마지막 열은 탐색 결과다. 새 상한은 σ = 1과 σ = 2에서 정확하고(경로 P₄와 사이클 C₇), σ = 3에서는
1, σ = 4에서는 2만큼 크다.

## 3. σ ≤ 4 탐색

SMAX=4로 실행한 [`prune189.c`](prune189.c)는 중간 단계든 최종 단계든, 어떤 정점으로부터 거리
2에 있는 정점이 넷보다 많거나, 끝에 차수가 4 이하로 남을 수 있는 정점이 너무 적은 그래프를
버린다. SMAX=3에 대한 README의 논증이 그대로 적용된다. 유도 부분그래프에서 거리가 2이면 전체
그래프에서도 거리가 2이고, `geng`의 유도 부분그래프 사슬을 따라 차수는 늘어나기만 한다. 따라서
정점이 n개이고 σ ≤ 4인 (H) 그래프는 모두 위수 n의 가지치기를 통과한다. `search_reduction_four`는
n을 15 이하로 제한하고, n = 15에서 `geng -d4`를 정당화한다. 이어서 `hyp189`, `ind189`,
`certify.py --sigma4`가 살아남은 그래프를 모두 읽으며, σ = 4인 (H) 그래프에 대해 판정이 일치한다.

| ---: | ---: | ---: | ---: |
| 2–4 | 1, 2, 6 | 1, 2, 5 | 0 |
| 5 | 21 | 15 | 1 |
| 6 | 111 | 50 | 8 |
| 7 | 808 | 235 | 67 |
| 8 | 7,623 | 1,311 | 1,018 |
| 9 | 54,274 | 17,112 | 17,012 |
| 10 | 133,566 | 33,462 | 33,433 |
| 11 | 136,772 | 7,186 | 7,186 |
| 12 | 166,081 | 2,044 | 2,044 |
| 13 | 341,208 | 285 | 285 |
| 14 | 1,001,800 | 0 | 0 |
| 15 (`-d4`) | 23 | 0 | 0 |

n ≤ 11에서는 이 개수가 가지치기 없는 탐색의 σ = 4 개수와 정확히 같고, n ≤ 10에서는 가지치기
없는 `geng`이 같은 graph6 문자열을 낸다. 세 번째 열의 나머지 그래프는 σ ≤ 3이고, 그 개수는
`sigma3_certificates.txt`와 일치한다.

## 4. σ = 4 데이터가 보여 주는 것

σ = 4인 (H) 그래프 61,054개는 [`sigma4_certificates.txt`](sigma4_certificates.txt)에 실려 있다.
σ ≤ 3의 완전한 목록과 함께 보면 다음을 알 수 있다. 이 가운데 형식화된 것은 없다.

- **가장 큰 그래프.** σ = 1, 2, 3, 4에서 가장 큰 (H) 그래프의 정점 수는 n = 3σ + 1이고, 그런
  그래프는 각각 1개(P₄), 5개, 29개, 285개다. σ가 짝수이면 순환 그래프 C_{3σ+1}(1, …, σ/2)가
  있으므로 3σ + 1에 언제나 도달한다. 이 그래프는 σ-정칙이고 각 정점으로부터 거리 2와 거리 3에
  정점이 σ개씩 있으므로, 모든 정점에서 dist_even = σ + 1이다. σ = 4이면 C₁₃(1, 2)이고, 285개
  가운데 유일한 정칙 그래프다.
- **증명이 잃는 곳.** σ ≤ 4인 모든 (H) 그래프에서, 차수가 σ인 모든 정점 x는 |O(x)| ≤ σ를
  만족한다. σ = 3과 σ = 4에서는 차수가 더 큰 정점이 σ + 1에 이른다. 차수가 σ인 정점에서
  |O(x)| ≤ σ를 증명하면 n ≤ 3σ + 1을 얻고, 이는 σ가 짝수일 때 정확하다. 횡단 집합 논법은
  |O(x)| ≤ ⌊(σ + 1)²/4⌋만 주며, 이는 σ = 4에서 6이다. 예를 들어 C₁₃(1, 2)에서 이 논법은 s = 2를
  잡고 y ∈ Y마다 O(x)의 정점을 셋까지 허용하지만, 실제로는 둘뿐이다.
- **위쪽 끝에서 가설은 빠듯하다.** n = 12 또는 13인 σ = 4 (H) 그래프는 모두
  max dist_even = 5 = σ + 1이다. n = 12의 2,044개 가운데 155개와 n = 13의 285개 가운데 44개는
  모든 정점에서 dist_even = 5이다.
- **n = 13에서의 모양.** 285개 가운데 283개는 최소 차수가 4이고 2개는 3이다. 266개는 지름이 3,
  19개는 지름이 4이다. 최소 차수인 정점에서 본 거리 층의 크기는 264개에서 (1, 4, 4, 4), 14개에서
  (1, 4, 3, 4, 1), 5개에서 (1, 4, 2, 4, 2), 2개에서 (1, 3, 4, 5)이다.
- **해밀턴 사이클.** 해밀턴 사이클이 없는 σ = 4 (H) 그래프는 절단점이 있는 그래프
  (Easwar–Johari의 네 번째 경우)와 n = 9의 2-연결 그래프 19개뿐이다. n = 10부터는 2-연결인
  σ = 4 (H) 그래프가 모두 해밀턴 사이클을 가진다. 특히 Easwar–Johari의 정리가 남겨 둔 그래프는
  모두 해밀턴 사이클을 가지며, 이는 추측이 요구하는 것보다 강하다.

마지막 열은 2-연결이고, 지름이 3 이상이며, n ≥ 2σ + 4 = 12인 그래프의 수다. Easwar와 Johari의
정리 B는 이 경우를 다루지 않는다. 탐색은 이 2,243개를 추적 가능하다고 알려진 경우에 더한다.
또한 정점이 14개나 15개인 σ = 4 (H) 그래프가 없음을 보여 준다.

## 5. σ = 5

σ = 5이면 상한은 n ≤ 20이고, 차수 상한 n ≤ deg(x) + 15는 n = 17부터만 `geng`을 제한한다.
SMAX=5로 같은 가지치기 탐색을 하면 위수가 하나 늘 때마다 20–30배씩 커진다.

| n | 가지치기 후 그래프 | CPU 시간 |
| ---: | ---: | ---: |
| 9 | 213,221 | 0.08초 |
| 10 | 4,137,667 | 2.5초 |
| 11 | 47,134,920 | 80초 |
| 12 | 약 1억 1천만 | 약 28분 |

n = 12 행은 64개 조각 가운데 0, 21, 42번 조각(`geng -c 12 r/64`)에서 외삽한 값이다. 각 조각은
24–29초가 걸렸고 그래프를 약 170만 개씩 남겼다. 이 속도라면 n = 13에 CPU 시간으로 약 반나절이
필요하고, 위수가 하나 늘 때마다 비용이 다시 그만큼 곱해지므로 σ = 5는 시도하지 않았다. 데이터가
시사하는 상한 n ≤ 3σ + 1 = 16으로도 감당할 수 없다. 차수가 σ인 정점으로부터의 거리 층을 따라
짜는 탐색이라면 가능할지도 모른다.

## 6. 효과가 없었던 접근

- **간선 항등식.** 간선 xy에 대해 어떤 정점에서든 x까지의 거리와 y까지의 거리는 많아야 1
  차이 나므로 n = dist_even(x) + dist_even(y) + |OO(xy)| − |EE(xy)|이다. 여기서 OO(xy)와
  EE(xy)는 양 끝점 모두로부터 각각 홀수 거리, 짝수 거리에 있는 정점들의 집합이다. 정점 상한보다
  나은 OO(xy)의 상한은 찾지 못했다.
- **유도 경로.** 유도 경로 x–y–w에 대해, x, y, w 가운데 v로부터 짝수 거리에 있는 정점의 수를
  c(v)라 하자. 이중 셈으로
  n = Σ_r dist_even(r) − Σ_{c(v) ≥ 1} (c(v) − 1) + |U|를 얻는다. 여기서 r은 x, y, w를 지나고,
  U는 세 정점 모두로부터 홀수 거리에 있는 정점들의 집합이다. (H) 아래에서 이는
  n ≤ 3(σ + 1) + |U|에서 겹치는 부분을 뺀 값이 되는데, U를 충분히 잘 제한하지 못했다.
