# Mathematical details: Equation 677 and Equation 255 in finite magmas

This note justifies every reduction, clause and propagation rule used by the
searches in this directory. Lean names refer to
[`Etp677Implies255Finite.lean`](../../AgenticConjectures/Etp677Implies255Finite.lean),
where each cited fact is proved without `sorry`.

Notation: $(M,\diamond)$ is a magma and $L_y(x)=y\diamond x$.

- E677: $x=y\diamond(x\diamond((y\diamond x)\diamond y))$ for all $x,y$.
- E255: $x=((x\diamond x)\diamond x)\diamond x$ for all $x$. "E255 at $x$"
  means this identity for one fixed $x$.
- A *countermodel* is a finite magma that satisfies E677 but not E255.

## 1. Facts about finite E677 magmas

Let $M$ be finite and satisfy E677.

| | Fact | Lean |
|---|---|---|
| F1 | every $L_y$ is a bijection, with $L_y^{-1}(x)=x\diamond((y\diamond x)\diamond y)$ | `leftMul_surjective`, `leftMul_bijective` |
| F2 | if $y\diamond c=x$ then $x\diamond((y\diamond x)\diamond y)=c$ | `inv_form` |
| F3 | if $y\diamond c=x$ and $x\diamond b=c$ then $(y\diamond x)\diamond y=b$ | `inv_form₂` |
| F4 | if $y\diamond x=x$ then $y=(x\diamond x)\diamond x$ | `fixer_unique` |
| F5 | E255 holds at $x$ iff $y\diamond x=x$ for some $y$ | `eq255_at_iff_exists_fixer` |
| F6 | if E255 fails at $x$, then $y\diamond x\ne x$, $x\diamond(z\diamond x)\ne z$ and $x\diamond(y\diamond y)\ne y$ for all $y,z$ | `fixer_free_of_not255`, `ne_of_not255_v`, `ne_of_not255_vii` |

F1 uses finiteness (surjective implies injective). F4–F6 are Lemmas 13.1–13.2
of the ETP blueprint chapter on Equation 677.

## 2. Reduction to one-generated countermodels

If $M$ is a countermodel and E255 fails at $x$, the submagma $\langle x\rangle$
generated by $x$ satisfies E677, has at most $|M|$ elements, is generated by
$x$, and E255 fails at $x$ in it (`exists_generated_countermodel`; the
equivalence form is `not_statement_iff`). Therefore

$$
\text{no countermodel has at most } N \text{ elements}
\iff
\begin{array}{l}\text{for every } n\le N \text{ there is no E677 magma on } n \text{ elements}\\
\text{generated by one element } g \text{ at which E255 fails.}\end{array}
$$

The left side is `noCountermodelUpTo N`. Every search below works with a
fixed size $n$ and must be run for all $n\le N$.

## 3. Canonical labelling

Let $(M,g)$ be a magma of size $n$ generated by $g$. Label $g$ as $0$. When
$0,\dots,k$ are labelled ($k<n-1$), the set $\{0,\dots,k\}$ is not closed
under $\diamond$ (a closed set containing $g$ is all of $M$), so some pair in
$\{0,\dots,k\}^2$ has an unlabelled product; take the first such pair in
row-major order and give its product the label $k+1$. The multiplication table
$T$ of the labelled magma has property

> (C) for every $k\le n-2$, some pair in $\{0,\dots,k\}^2$ has $T$-value
> $>k$, and the row-major first such pair has value exactly $k+1$.

Every table with (C) is generated by $0$, and the labelling is forced step by
step, so tables with (C) correspond one-to-one to isomorphism classes of
pointed magmas $(M,g)$ generated by $g$. The negative results only use that
every such $(M,g)$ has a table with (C); the counts in general mode also use
uniqueness.

## 4. SAT encoding ([`search/gen_cnf.py`](search/gen_cnf.py))

Variables $p(x,y,v)\iff x\diamond y=v$ on $\{0,\dots,n-1\}$, auxiliaries
$q(x,y,b)$ and $r(x,y,b)$, and the order variables of (C). Clauses:

1. every cell has exactly one value;
2. every row is a permutation (F1);
3. $y\diamond x=a\wedge a\diamond y=b\Rightarrow q(x,y,b)$;
4. $q(x,y,b)\wedge x\diamond b=c\Rightarrow y\diamond c=x$ (E677);
5. $q(x,y,b)\wedge y\diamond c=x\Rightarrow x\diamond b=c$ (F2);
6. $y\diamond c=x\wedge x\diamond b=c\Rightarrow r(x,y,b)$;
7. $y\diamond x=a\wedge r(x,y,b)\Rightarrow a\diamond y=b$ (F3);
8. anti-E255 mode only: $y\diamond 0\ne 0$ and $v\diamond 0=w\Rightarrow
   0\diamond w\ne v$ (F6 at $0$);
9. (C): for each $k$, one clause says that some pair of
   $\{0,\dots,k\}^2$ has value $>k$; variables $e_t$ ("some pair before
   position $t$ in row-major order has value $>k$") satisfy
   $\text{value}(t)\ge k+2\Rightarrow e_t$ and
   $e_t\Rightarrow e_{t-1}\vee\text{value}(t-1)>k$, with $e_0$ false.

If an E677 magma of size $n$ generated by $g$ with E255 failing at $g$
existed, its table with (C), together with $q(x,y,b):=[(y\diamond x)\diamond
y=b]$, $r(x,y,b):=[\exists c\; y\diamond c=x\wedge x\diamond b=c]$ and the
intended $e_t$, would satisfy every clause. So UNSAT of the anti-mode CNF
for size $n$ proves there is no such magma. Conversely, clauses 1–4 force
E677 on the table, so in general mode (clause 8 omitted) the $p$-parts of the
models are exactly the tables with (C) that satisfy E677;
[`search/enum_sat.py`](search/enum_sat.py) enumerates them with blocking
clauses on $p$.

## 5. Exhaustive DFS ([`search/dfs677.cpp`](search/dfs677.cpp))

The program fills a partial table with domains. Let $k$ be the largest
label created so far. All assigned cells and values stay in
$\{0,\dots,k\}$: branching uses values $\le k+1$ (value $k+1$ creates the
next label), and every propagated assignment has its row, column and value
taken from already assigned cells.

- **Static phase** ($k<n-1$): branch on the row-major first unassigned cell
  of $\{0,\dots,k\}^2$ with the values of its domain that are $\le k+1$. If
  $\{0,\dots,k\}^2$ is fully assigned, $\{0,\dots,k\}$ is closed and the
  branch is dead. Along the path of a table $T$ with (C), the earlier cells
  of $\{0,\dots,k\}^2$ carry values $\le k$, so by (C) the branching cell has
  value $\le k+1$ and $T$ is never cut off.
- **Dynamic phase** ($k=n-1$): branch on a cell with the smallest domain.
- **Propagation**: the E677 chain $a=y\diamond x$, $b=a\diamond y$,
  $c=x\diamond b$, $y\diamond c=x$ is propagated forwards and backwards with
  $c'=L_y^{-1}(x)$ and $b'=L_x^{-1}(c')$, using F1–F3; rows are permutations
  (F1, including hidden singles once all labels exist); a fixer of $x$ is
  unique and equals $(x\diamond x)\diamond x$ (F4); in anti mode the three
  inequalities of F6 hold at $0$. Each rule removes only values that no table
  with (C) satisfying the constraints can take.
- Complete tables are re-checked against E677 (and against E255 failing at
  $0$ in anti mode) before they are counted.
- **Splitting**: the search is deterministic. With `split P p depth d`,
  nodes at depth $d$ are numbered in DFS order and part $p$ explores only
  those with number $\equiv p \pmod P$; the $P$ parts cover the whole tree.
  `split2` subdivides one part in the same way at a deeper level.

The DFS and the SAT encoding share only the mathematics above, not code; for
$n\le 10$ both report no anti-mode solutions, and for $n\le 9$ the general
mode tables coincide.

## 6. Translation-invariant magmas on groups

Let $G$ be a finite group and $f:G\to G$. The operation
$x\diamond y=x\,f(x^{-1}y)$ makes every left translation of $G$ an
automorphism (`tinv_translate`). In Lean:

- E677 holds iff $x=f\bigl(x\,f(x^{-1}u)\bigr)$ for all $x$, where
  $u=f(x)\,f(f(x)^{-1})$ (`tinv_eq677_iff`);
- if E677 holds, E255 holds iff $f$ has a fixed point (`tinv_eq255_iff`);
- a fixed-point-free solution refutes the statement
  (`not_statement_of_tinv`);
- every fixed-point-free solution is a bijection with
  $f(z\,f(z^{-1}))\ne z$ and $f(y\,f(e))\ne y$ (`tinv_cnf_constraints`).

**CNF** ([`tinv/tinv_cnf.py`](tinv/tinv_cnf.py)). Variables $F(z,v)\iff
f(z)=v$, with auxiliaries $U(x,u)$ ("$u=f(x)f(f(x)^{-1})$") and $R(x,u)$.
Clauses: $f$ is a permutation without fixed points; $U$ is implied by its
definition; $U(x,u)\wedge f(c)=d\Rightarrow f(xd)=x$ with $c=x^{-1}u$ (the
functional equation); $U(x,u)\wedge f(xd)=x\Rightarrow f(c)=d$ (injectivity);
$f(c)=d\wedge f(xd)=x\Rightarrow R(x,u)$ and $f(x)=a\wedge R(x,u)\Rightarrow
f(a^{-1})=a^{-1}u$ (injectivity, as in F3); and the two inequalities of
`tinv_cnf_constraints`. A fixed-point-free solution, with $U$, $R$ given their
intended values, satisfies every clause.

**Symmetry breaking.** For $\varphi\in\operatorname{Aut}(G)$ the conjugate
$\varphi\circ f\circ\varphi^{-1}$ is again a solution
(`tinv_conj_solution`), and it has a fixed point iff $f$ has one
(`tinv_conj_fixed_iff`). Since its value at $e$ is $\varphi(f(e))$, we may
assume that $a=f(e)$ is the least element (in our numbering) of its
$\operatorname{Aut}(G)$-orbit; conjugating further by the stabilizer of $a$
keeps $f(e)=a$ and moves $f(a)$ inside its $\operatorname{Stab}(a)$-orbit, so
we may assume $b=f(a)$ is the least element of that orbit. Each case adds the
unit clauses $f(e)=a$ and $f(a)=b$ (cases with $a=e$ or $b=a$ are omitted
because $f$ has no fixed points). Only the *generators* of
$\operatorname{Aut}(G)$ come from GAP;
[`tinv/export_cases.py`](tinv/export_cases.py) checks that each generator is
an automorphism of the exported Cayley table and computes the orbits and the
stabilizer generators (Schreier's lemma) itself. If GAP returned too few
generators, the case split would only be weaker, never unsound.
[`tinv/test_sb.py`](tinv/test_sb.py) checks in general mode, on all 50 groups of
order at most 19, that the $\operatorname{Aut}(G)$-conjugates of the case
solutions are exactly all solutions.

## 7. What is trusted

- **DRAT bound ($n\le 10$)**: `gen_cnf.py` and the argument of §2–§4 (the
  facts used are Lean-checked), and `drat-trim`. The solver is not trusted.
- **DFS bound ($n\le 10$)**: the C++ program and the argument of §5; there is
  no certificate. It is an independent second method for $n\le10$. Its
  $n=11$ run was stopped with 3 of 27 subtrees unfinished and supports no
  claim.
- **Translation-invariant searches**: CaDiCaL's UNSAT answers (no proofs are
  kept), the group tables from GAP's SmallGroups library (each is checked to
  be a group by `tinv_cnf.py`), and the case split of §6.
