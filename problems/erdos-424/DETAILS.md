# Erdős #424: mathematical and computational details

$S$ is the upstream `generatedSet`, the union of all $A_k$, where
$A_0=\{2,3\}$ and $A_{k+1}=A_k\cup\{xy-1 : x,y\in A_k,\ x\ne y\}$. We write
$A(N)=\#(S\cap[0,N])$.
Section numbers are referenced from the [README](README.md). Statements marked
**(Lean)** are proved in
[`Erdos424.lean`](../../AgenticConjectures/Erdos424.lean). Statements marked
**(checked)** are finite computations re-run by
[`verify_counts.py`](verify_counts.py). Everything else is explanation or
heuristics.

## 1. The recursion behind the sieves

**(Lean)** $S$ is the least set containing $2,3$ and closed under
$(x,y)\mapsto xy-1$ for $x\ne y$ (`mul_sub_one_mem`, `induction_on`).
Equivalently, $n\in S$ iff $n\in\{2,3\}$ or $n=xy-1$ for distinct members
(`mem_generatedSet_iff`). Every member is $\ge2$, so distinct members have
$xy\ge6$ and $x,y<xy-1$ (`lt_mul_sub_one`). Hence for $n\ge4$:

$$n\in S\iff n+1=xy\text{ for some }2\le x<y\text{ with }x,y\in S,$$

and both factors are at most $(n+1)/2<n$. Implementation A uses exactly
this: once the scan reaches $y$, its bit is final, and it pushes $xy-1$ for
all smaller members $x$ with $xy-1\le N$. Implementation B instead iterates the
generations. Truncating them to $[0,N]$ is exact, because a product $\le N+1$
only involves factors $\le(N+1)/2$. B is semi-naive: generation $k+1$
multiplies only pairs with a factor first seen in generation $k$, against the
frozen $A_k$. New products go to a second bit plane, written only where $n$ is
not yet in $A_k$, so a generation never sees its own output.

## 2. The residue obstruction and the upper bound

**(Lean, `mod_three_ne_one`)** Members are $\equiv0$ or $2\pmod 3$. If
$x,y\in\{0,2\}\pmod 3$ then $xy\in\{0,1\}\pmod3$, so
$xy-1\in\{2,0\}\pmod 3$.

**(Lean, `three_mul_countingFn_le`)** There are exactly
$\lfloor N/3\rfloor+\lfloor(N+1)/3\rfloor$ integers $2\le n\le N$ with
$n\not\equiv1\pmod3$ (`card_filter_admissible`). This is $\le2N/3$, so
$3A(N)\le2N$. Any limit of $A(N)/N$ is therefore $\le2/3$
(`le_two_thirds_of_tendsto`).

**(checked)** For every $2\le m\le1000$, the least $R\subseteq\mathbb Z/m$
with $2,3\in R$ and $ab-1\in R$ for all $a,b\in R$ is exactly
$\{r : 3\nmid m\text{ or }r\not\equiv1\ (3)\}$. Since $S\bmod m\subseteq R$,
this closure argument yields no obstruction beyond the one modulo 3. CI checks
$m\le300$; `--closure-limit 1000` checks $m\le1000$, which adds about 11 s. The
recorded tallies at $10^{10}$ show that every class $\not\equiv1\pmod 3$
modulo each of the 26 recorded moduli is occupied.

## 3. Infinite families and the lower bound

**(Lean)** $2^k+1\in S$ for $k\ge1$, because $2(2^k+1)-1=2^{k+1}+1$.

**(Lean)** If $n+1$ is prime and $n\ge4$, then $n\notin S$: a prime has no
factorization $xy$ with $x,y\ge2$. If $p\equiv1\pmod3$ is prime, then
$3p-1\notin S$: the only factorization of $3p$ with both factors $\ge2$ is
$3\cdot p$, and $p\notin S$ by the residue obstruction. With Dirichlet's
theorem in the form `Nat.exists_prime_gt_modEq_one`, both admissible classes
modulo 3 contain infinitely many non-members.

**(Lean, `le_sixteen_mul_countingFn_sq`)** Let $c(N)$ count the odd
members in $[5,N]$. For odd $y\in S$ with $y\ge5$, both $2y-1$ and
$2(3y-1)-1=6y-3$ are odd members. They are $\equiv1$ and
$\equiv3\pmod 4$ respectively, and both are $\ge9$, so 5 lies in neither
image. Therefore

$$c(N)\ge1+c(\lfloor(N+1)/2\rfloor)+c(\lfloor(N+3)/6\rfloor)\qquad(N\ge5).$$

Induction then gives $N\le16\,c(N)^2$. The cases $5\le N\le26$ follow from
$5,9\in S$. For $N\ge27$, put $a=\lfloor(N+1)/2\rfloor$,
$b=\lfloor(N+3)/6\rfloor$ and $s=N-a-b$. Then $3s\le N+1$ and
$N^2\le 2a(6b+2)$, so $s^2\le4ab\le(32\,c(a)c(b))^2$, and

$$N=a+b+s\le16c(a)^2+16c(b)^2+32c(a)c(b)\le16\,c(N)^2.$$

Finally $A(N)\ge c(N)$. The free semigroup generated by $y\mapsto2y-1$ and
$y\mapsto6y-3$ actually gives $A(N)\gg N^{\alpha}$ with
$2^{-\alpha}+6^{-\alpha}=1$, $\alpha\approx0.6009$; only the exponent $1/2$ is
formalized. Both are far below the linear growth the data suggest.

## 4. The arithmetic part of the complement

Call $n$ *factorable* if $n+1=xy$ with $2\le x<y$ and
$x,y\not\equiv1\pmod 3$. Factorable numbers are themselves
$\not\equiv1\pmod3$. By §2, every member other than 2 and 3 is factorable.
Write $E(N)$ for the admissible $n\le N$, other than 2 and 3, that are not
factorable: they lie outside $S$ for arithmetic reasons. Write $D(N)$ for the
factorable $n\le N$ outside $S$, the *dynamic* misses. Then
$\#\{n\le N\text{ admissible}\}-A(N)=E(N)+D(N)$.

**Description (checked up to $10^5$ against divisor enumeration).** Let
$n\ge4$ be admissible.

- Odd $n$ is always factorable: $n+1=2\cdot\frac{n+1}2$, and
  $\frac{n+1}2\not\equiv1\pmod 3$.
- If $n\equiv0\pmod 6$, then $n+1\equiv1\pmod 6$, so both factors must be
  $\equiv2\pmod3$. Then $n$ is unfactorable iff $n+1$ has no prime factor
  $\equiv2\pmod 3$, or $n+1=p^2$ with $p\equiv2\pmod 3$ prime.
- If $n\equiv2\pmod 6$, write $n+1=3m$. Then $n$ is unfactorable iff $n=8$,
  or $3\nmid m$ and every prime factor of $m$ is $\equiv1\pmod 3$.

So $E$ consists of integers $n$ for which $n+1$, or $(n+1)/3$, is built only
from primes $\equiv1\pmod3$, up to a sparse exceptional set. Standard
estimates for integers all of whose prime factors lie in a set of primes of
relative density $1/2$ give a count of order $N/\sqrt{\log N}$ (as for sums of
two squares, Landau 1908; in general via Wirsing's mean-value theorem). So $E$
has density zero, but it decays very slowly. This estimate is not formalized
here.

## 7. Certification details

- The hash is computed over the 64-bit words of the bitset of $[0,N]$
  (bit $n$ is bit $n\bmod64$ of word $\lfloor n/64\rfloor$). Starting from
  $h=\texttt{0x424}$, each word $w$ updates $h\leftarrow f(h\oplus w)$, where
  $f$ is the splitmix64 finalizer. A and B compute it from their own final
  bitsets; Python recomputes it at $10^5$.
- A and B share only the output format and the hash function. They differ in
  generation order, data layout (one plane vs two interleaved planes) and loop
  nest. Their statistics passes are written separately: A uses one pass in
  bit order, B uses per-checkpoint prefix popcounts with masks.
- The Python references are deliberately naive. One iterates the upstream
  generations with set comprehension. The other factors $n+1$ by a
  smallest-prime-factor table and enumerates divisors.
- 64-bit arithmetic is safe: inputs are limited to $N\le2^{40}$, and every
  product formed is below $2^{42}$.
