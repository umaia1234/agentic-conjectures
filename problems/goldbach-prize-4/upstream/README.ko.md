# 원문 스냅숏 메타데이터

- 공식 페이지: <https://www.dimostriamogoldbach.it/en/prizes/>
- 조회일: 2026-08-12
- 문제 ID: 4
- 게시 상금: €100
- 게시 상태: `No solutions received`

원문은 다음 문장으로 시작한다.

> “Let n_1, n_2 and n_3 be prime numbers such that n_1 < n_2 < n_3.”

이어 모든 정수 (n>1)에 대해 양의 (h,k), 등식 (h+k=n), 그리고
(n_1h-1), (n_1k+1) 각각이 (n_2,n_3) 어느 것으로도 나누어지지 않을
것을 요구한다. 이 파일은 명제 충실성 대조에 사용한 웹 문구의 메타데이터를
기록하며, 공식 페이지가 최종 원문이다.
