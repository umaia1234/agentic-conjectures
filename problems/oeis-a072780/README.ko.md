# OEIS A072780: Goldbach형 동치 명제의 반례

## 판정

[OEIS A072780](https://oeis.org/A072780)의 Goldbach형 명제는 **거짓**이다.
이 항목은 \(n=m^2-r^2\)로 놓았을 때 다음과 같이 말한다.

> “\(m-r\)과 \(m+r\)이 합이 \(2m\)인 소수인 것과 \(a(n)=2\)인 것은
> 동치이다.”

\(m=8\), \(r=7\)로 두자. 그러면

\[
m^2-r^2=64-49=15,\qquad m-r=1,\qquad m+r=15.
\]

15의 양의 약수들로부터

\[
\sigma(15)=24,\qquad \sigma_2(15)=260,\qquad \varphi(15)=8
\]

을 얻으므로

\[
a(15)=260+8\cdot24-2\cdot15^2=2.
\]

하지만 1과 15는 모두 소수가 아니다. 따라서 주장된 동치에서 수열값
쪽은 참이고 소수성 쪽은 거짓이다.

실패 원인은 제곱차 인수분해의 비유일성이다. 같은 15는
\(4^2-1^2=3\cdot5\)이므로 수열값이 2인 이유를 설명하지만,
\(8^2-7^2=1\cdot15\)이기도 하다. 어떤 수가 서로 다른 두 소수의
곱이라는 사실만으로 선택한 모든 \((m-r)(m+r)\) 인수분해가 그 두
소수를 사용한다고 결론 내릴 수는 없다.

## 범위와 원문 충실성

정식 항목은 2026-08-12에 확인했다. revision 23의 offset은 1이며

\[
a(n)=\sigma_2(n)+\varphi(n)\sigma(n)-2n^2
\]

으로 정의한다. 반례는 양의 입력 \(n=15\)를 사용하므로 offset이나
0 경계값에서 생긴 현상이 아니다. 또한 원문이 요구하는 \(m>r\)을
만족하므로 \(m-r\)과 \(m^2-r^2\)의 자연수 뺄셈은 통상적인 정수
뺄셈과 일치한다.

상류 Formal Conjectures [소스 스냅샷](upstream/README.ko.md)은 바깥쪽
뺄셈을 \(\mathbb Z\)에서 계산한 뒤 `Int.toNat`을 적용한다. 이 저장소의
Lean 모듈은 그 정의를 그대로 보존한다. \(n=15\)에서는 정수식이
양수이므로 이 변환은 결과에 영향을 주지 않는다.

이 결과는 Goldbach형 동치와 이에 대응하는 상류 정리
`oeis_72780_goldbach_conjecture`만 반박한다. \(a(n)=0\)이 소수(및 1)를
특징짓는다는 별도 주장, \(a(n)=2\)가 서로 다른 두 소수의 곱을
특징짓는다는 주장, 쌍둥이 소수 특수화는 반박하지 않는다.

## 기계 검증

[`a072780_certificate.py`](a072780_certificate.py)는 Python 표준
라이브러리만 사용하며 같은 반례를 서로 독립적인 두 방식으로 계산한다.

- 약수를 직접 열거하고 gcd 검사로 \(\varphi(15)\)를 계산한다.
- 시행 나눗셈 인수분해 뒤 \(\sigma\), \(\sigma_2\), \(\varphi\)의
  곱셈적 공식을 적용한다.

또한 소수성과 15의 두 인수분해를 독립적으로 검사한다. 저장소
루트에서 다음을 실행한다.

```bash
python3 problems/oeis-a072780/a072780_certificate.py
lake build AgenticConjectures.OeisA072780
```

2026-08-12 검증 머신에서 인증서는 0.05초에 실행되었다. 정리
`AgenticConjectures.OeisA072780.goldbach_conjecture_false`는 정확한 상류
전칭 명제의 부정을 Lean 4로 증명한다. 산술 계산에는 커널 `decide`를
사용하며 `sorry`, 추가 공리, `native_decide`는 없다.

## 선행 연구와 제출 상태

2026-08-12 현재 OEIS 항목에는 위 동치가 그대로 적혀 있었다. 수열
식별자, 정확한 주장, 반례값으로 OEIS, 공개 웹, arXiv, GitHub 코드,
Formal Conjectures 이슈와 pull request를 검색했지만 공개된 수정,
증명, 반례를 찾지 못했다. 이 음성 검색은 신규성의 증거가 아니다.
이 결과는 검토되지 않았고 신규성을 주장하지 않으며 OEIS나 다른
외부 채널에 아무것도 제출하지 않았다.
