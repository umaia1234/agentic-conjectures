# OEIS A397588 — 홀짝성 추측

[OEIS A397588](https://oeis.org/A397588)은 다음 점화식으로 수열을
정의합니다.

\[
a(1)=1,\qquad
a(n)=(n+1)\sum_{k=1}^{n-1}a(k)a(n-k)\quad(n>1).
\]

원문에 적힌 주장은 다음과 같습니다.

> Conjecture: a(n) is odd iff n is a power of 2 for n >= 1.

## 결과

이 추측은 참입니다. 모든 정수 \(n\geq1\)에 대해

\[
a(n)\text{이 홀수}\quad\Longleftrightarrow\quad
n=2^r\text{인 }r\geq0\text{가 존재}
\]

가 성립합니다.

## 증명

모든 계산을 2로 나눈 나머지에서 생각합니다. \(n>1\)이 홀수이면
점화식의 인수 \(n+1\)이 짝수이므로 \(a(n)\)도 짝수입니다.

이제 \(n=2m\)이라 합시다. 합성곱 합에서 대응
\(k\mapsto2m-k\)는 중점 \(k=m\)을 제외한 모든 항을 둘씩
짝짓습니다. 한 쌍의 두 항은 같은 곱이므로 그 합은 2로 나눈
나머지에서 사라집니다. 따라서 \(a(m)^2\)만 남습니다.
또한 \(2m+1\)은 홀수이므로

\[
a(2m)\equiv a(m)^2\equiv a(m)\pmod2. \tag{1}
\]

(1)을 반복하면 첨자의 모든 2의 인수를 제거할 수 있습니다.
\(n\)이 2의 거듭제곱이면 마지막에 \(a(1)=1\)에 도달하므로
\(a(n)\)은 홀수입니다. 그렇지 않으면 1보다 큰 홀수 첨자에
도달하며, 첫 문단에 의해 그 항은 짝수입니다. 따라서 양방향이
모두 증명됩니다.

## Lean 검증

[`AgenticConjectures/OeisA397588.lean`](../../AgenticConjectures/OeisA397588.lean)은
임의의 함수 `a : ℕ → ℕ`에 대해 점화식을 형식화하고 다음의 더
강한 전칭 정리를 증명합니다.

```text
statement :=
  ∀ a, SatisfiesRecurrence a →
    ∀ n, 0 < n → (Odd (a n) ↔ ∃ r, n = 2 ^ r)

odd_iff_power_of_two : statement
```

합성곱의 소거는 `ZMod 2` 위 유한합의 대합으로 검증하며, 계산된
항의 표를 가정하지 않습니다. 저장소 루트에서 다음 명령으로 모듈을
재현할 수 있습니다.

```bash
lake env lean AgenticConjectures/OeisA397588.lean
```

전체 저장소 게이트도 이 모듈을 컴파일하고 `sorry`와 비표준 공리를
거부하며 대시보드를 재생성합니다. 로컬 검증 머신에서 위 단독
명령은 41.99초가 걸렸습니다.

## 명제 충실성과 연구 상태

형식화는 OEIS 항목에 두 번째로 적힌 점화식을 사용하며,
`Finset.Icc 1 (n - 1)`은 \(n>1\)일 때 정확히
\(k=1,\ldots,n-1\)을 나타냅니다.
생성함수 방정식 \(A(x)=x+(xA(x)^2)'\) 자체는 형식화하지 않았습니다.
이 방정식에서 계수를 추출하면 OEIS에 적힌 위 점화식이 나오지만,
그 유도는 여기서 문서화만 했고 Lean으로 검증하지는 않았습니다.
오프셋은 1이고 \(n=0\)은 제외합니다. 자연수 뺄셈 `n-k`는
\(1\leq k<n\)인 범위에서만 사용합니다.

점화식, 함수 방정식, 초항 및 저장소 형식화를 대상으로 한 검색에서는
공개된 증명을 찾지 못했습니다. 이러한 부정적 검색은 문헌 조사나
신규성의 근거가 아닙니다. 이 증명은 검토되지 않았고 우선권을 주장하지
않으며 OEIS에 제출하지도 않았습니다.
