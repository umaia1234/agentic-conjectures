# 각기둥, 뫼비우스 사다리, 엇각기둥의 연결 유도 부분그래프

OEIS [A286182](https://oeis.org/A286182)(각기둥),
[A286185](https://oeis.org/A286185)(뫼비우스 사다리),
[A286183](https://oeis.org/A286183)(엇각기둥)에 추측으로 올라와 있는 닫힌 형식을
증명하고, 같은 항목들에 추측으로 올라와 있는 선형 점화식과 생성함수를 유도한다.

각기둥의 경우는 **새로운 결과가 아니다**. A. Vince, *The average size of a
connected vertex set of a graph — explicit formulas and open problems*,
J. Graph Theory **97** (2021) 82–103의 보조정리 7.2가 (합성/이항계수라는 다른
논증으로) 이미 증명했다. 여기 포함한 이유는 똑같은 세 줄 계산이 세 계열을 모두
처리하기 때문이고, 출판된 결과에 대해 방법을 검증해 주기 때문이다. 뫼비우스
사다리와 엇각기둥에 대해서는 문헌에서 증명을 찾지 못했다. 수행한 검색은
[README.md](README.md)를 보라. 셋 중 어느 것에 대해서도 **독창성을 주장하지 않는다**.

## 0. 설정

`n ≥ 1`을 고정한다. 세 그래프 모두 꼭짓점 집합은 `V = Z_n × {0,1}`이며,
`{i} × {0,1}`을 *열 i*라 부르고 `(i,r)`를 열 `i`의 행 `r`이라 쓴다. 모든 그래프는
**가로대** `(i,0) ~ (i,1)`을 포함하고, 이웃한 열을 잇는 방식에서만 차이가 난다.
아래의 모든 열간 변에는 `i ≠ j` 조건이 붙는데, 이것이 OEIS가 포함하는 퇴화 경우
`n = 1,2`에서도 그래프를 단순 그래프로 유지해 준다.

| 그래프 | 열 `i`와 `i+1` 사이의 변 |
|---|---|
| 각기둥 `CL_n = C_n □ K₂` | `(i,0)~(i+1,0)`, `(i,1)~(i+1,1)` |
| 뫼비우스 사다리 `ML_n` | 같음. 단 `i = n-1`에서는 두 변이 **꼬인다**: `(n-1,0)~(0,1)`, `(n-1,1)~(0,0)` |
| 엇각기둥 `AP_n` | `(i,0)~(i+1,0)`, `(i,1)~(i+1,1)`, 그리고 **대각선** `(i,1)~(i+1,0)` |

`ML_n`에서 세로대들은 하나의 `2n`-순환
`(0,0)(1,0)…(n-1,0)(0,1)(1,1)…(n-1,1)`을 이루고 가로대는 그 대척점끼리를 이으므로,
`ML_n`은 통상적인 의미의 뫼비우스 사다리다. `AP_n`은 `n ≥ 3`에서 4-정규이고
`AP_3`은 정팔면체다. `n = 1`에서는 셋 다 `K₂`이고, `n = 2`에서 각기둥은 `C₄`,
`ML_2 = AP_2 = K₄`이다. 이는 OEIS의 `a(1) = 3`, `a(2) = 13, 15, 15`와 일치한다.

`a(n)`을 유도 부분그래프가 연결인 공집합 아닌 `S ⊆ V`의 개수라 하자. `S ⊆ V`에
대해 `c_i = {r : (i,r) ∈ S}`라 쓰고, `c_i ≠ ∅`인 열을 *채워졌다*고 하며, 채워진
세 가지 상태를 다음과 같이 줄여 쓴다.

    A = {0},   B = {1},   C = {0,1}.

채워진 두 열 `i`, `i+1`이 **연결됨(linked)** 이란, 그래프의 어떤 변이 `c_i`에
속한 열 `i`의 꼭짓점과 `c_{i+1}`에 속한 열 `i+1`의 꼭짓점을 잇는다는 뜻이다.
**열 그래프** `H(S)`를 정의한다: 꼭짓점은 채워진 열들, 변은 연결된 순환 인접쌍.

**보조정리 0 (수축).** 유도 부분그래프의 연결성분은 `H(S)`의 연결성분과 대응한다.
특히 `S`가 연결일 필요충분조건은 `H(S)`가 연결인 것이다.

*증명.* 채워진 각 열은 그 자체로 연결이다: `A`, `B`는 한 점이고 `C`는 가로대
변이다. 그래프의 모든 변은 한 열 안에 있거나 순환적으로 이웃한 두 열을 잇고,
후자는 그 두 열이 연결되어 있을 때 정확히 유도 부분그래프에 나타난다. 유도
부분그래프의 경로를 열 수열로 사영하고 중복을 지우면 `H(S)`의 걷기가 되고, 역으로
`H(S)`의 변은 유도 부분그래프의 변으로 올라간다. ∎

"연결됨"은 순환 순서로 읽어야 한다: `H(S)`의 경로는 한 바퀴 돌아갈 수 있다.
(예컨대 `CL_4`에서 배치 `ABCC`는 열 0과 1이 연결되어 있지 않지만 `0–3–2–1`을 통해
한 성분에 있다.)

연결 여부는 `(c_i, c_{i+1})`에만 의존하므로 `A, B, C`로 첨자가 붙은
`{0,1}`-행렬로 기술된다. 공집합 아닌 두 행 집합은 `{0}`과 `{1}`인 경우를 빼면
만나므로:

* **각기둥과 뫼비우스의 세로대.** 연결됨 ⟺ `c_i ∩ c_{i+1} ≠ ∅` ⟺
  `{c_i, c_{i+1}} ≠ {A,B}`. 전이행렬(순서 `A,B,C`)

      M = [[1,0,1],
           [0,1,1],
           [1,1,1]],     특성다항식 (x-1)(x²-2x-1),  고윳값 1, 1±√2.

* **뫼비우스의 꼬인 이음매.** 열 `n-1`은 행 교환 `σ : A↔B, C↦C`를 통해 열 `0`을
  보므로, 이음매가 연결됨 ⟺ `c_{n-1} ∩ σ(c_0) ≠ ∅`이고 이음매 행렬은 `M·P_σ`다
  (`P_σ`는 `σ`의 치환행렬). `σ`가 연결 관계의 자기동형이므로 `M P_σ = P_σ M`이다.

* **엇각기둥.** 대각선 `(i,1)~(i+1,0)`이 *순서쌍* `(A,B)`도 연결시키고, `(B,A)`를
  연결시키는 변은 없다. 전이행렬

      Mₐ = [[1,1,1],
            [0,1,1],
            [1,1,1]],    특성다항식 (x)(x²-3x+1),  고윳값 0, (3±√5)/2.

이하에서 `P` = A000129(펠 수, `P₀=0, P₁=1, P_{m+2}=2P_{m+1}+P_m`),
`Q` = A002203(`Q₀=Q₁=2`, 같은 점화식, `Q_m = (1+√2)^m + (1-√2)^m`),
`t` = A001333 `= Q/2` (`1,1,3,7,17,41,…`)이고, `F`, `L`은 피보나치·뤼카 수라서
A001906`(m) = F(2m)`, A005248`(m) = L(2m)`이다.

## 1. 연속성과 두 경우

`S`가 연결이고 어떤 열이 비어 있으면, 채워진 열들은 순환 구간(*호*)을 이룬다.
빈 열에는 꼭짓점이 없으므로 보조정리 0에 의해 어떤 경로도 그곳을 지나지 못하고,
서로 다른 두 호에 놓인 채워진 열들은 다른 성분에 있게 된다. 따라서 모든 연결된
`S`는 정확히 다음 중 하나에 속한다.

* **(I)** 어떤 열이 비어 있다 — 채워진 열들이 길이 `m` (`1 ≤ m ≤ n-1`)의 호를 이룬다.
* **(II)** 모든 열이 채워져 있다.

경우 (II)의 연결 배치 개수를 `g(n)`이라 쓴다.

## 2. 경우 (I): 호

`f(m)`을, 주어진 연속한 `m`개 열의 호를 정확히 채우는 연결 배치의 개수라 하자
(`1 ≤ m ≤ n-1`).

`1 ≤ m ≤ n-1`이면 길이 `m` 호의 `n`개 평행이동은 서로 다른 집합이고(여집합이
비어 있지 않으므로 호의 첫 원소가 잘 정의된다), 호의 열 그래프는 변이 정확히
`m-1`개인 **경로**다. 양 끝 `s`와 `s+m-1`이 순환적으로 인접하려면
`m-1 ≡ ±1 (mod n)`, 즉 `m = 2`(이때 그 인접쌍이 바로 그 하나뿐인 내부 인접쌍이다)
이거나 `m ≡ 0 (mod n)`이어야 하는데 후자는 `m ≤ n-1`이 배제한다. (`m = n-1`에서
빠듯하다.) 따라서 보조정리 0에 의해 `f(m)`은 `m-1`개의 이웃쌍이 모두 연결된
낱말 `w ∈ {A,B,C}^m`의 개수다.

    f(m) = 1ᵀ Mᵐ⁻¹ 1        (각기둥, 뫼비우스),
    f(m) = 1ᵀ Mₐᵐ⁻¹ 1       (엇각기둥).

뫼비우스에서는 호가 꼬인 이음매를 포함할 수 있는데, 이음매 뒤의 모든 열에 `σ`를
적용하면 꼬인 연결을 보통 연결로 바꾸면서 나머지는 보존하는 전단사가 되므로
(`σ`는 연결 관계의 자기동형) `f(m)`은 각기둥과 같다.

**각기둥/뫼비우스.** 마지막 글자로 나누어, `A, B, C`로 끝나는 그런 낱말의 수를
`a_m, b_m, c_m`이라 하면

    a_{m+1} = a_m + c_m,  b_{m+1} = b_m + c_m,  c_{m+1} = a_m + b_m + c_m,
    a_1 = b_1 = c_1 = 1.

`A↔B` 대칭에 의해 `a_m = b_m`이고, 그러면 `a_{m+1} = a_m + c_m`,
`c_{m+1} = 2a_m + c_m`은 정확히 펠 점화식이라 `(a_m, c_m) = (P_m, t_m)`이다. 따라서

    f(m) = 2 P_m + t_m.                                                  (1)

`Σ_{m=0}^{k} t_m = P_{k+1}`과 `Σ_{m=1}^{k} P_m = (P_k + P_{k+1} - 1)/2`를 쓰면

    Σ_{m=1}^{n-1} f(m) = (P_{n-1} + P_n - 1) + (P_n - 1)
                       = P_{n-1} + 2P_n - 2 = P_{n+1} - 2.                (2)

**엇각기둥.** 여기서는 `1ᵀ Mₐ^{m-1} 1 = F(2m+2)`이다(양변이 같은 두 초기값
`3, 8`을 갖고 `x_{m+1} = 3x_m - x_{m-1}`을 만족한다). 따라서

    f(m) = F(2m+2) = A001906(m+1),
    Σ_{m=1}^{n-1} f(m) = Σ_{k=2}^{n} F(2k) = F(2n+1) - 2,                (2ₐ)

여기서 `Σ_{k=1}^{n} F(2k) = F(2n+1) - 1`을 썼다.

그러므로 경우 (I)의 기여는 각기둥과 뫼비우스에서 `n (P_{n+1} - 2)`, 엇각기둥에서
`n (F(2n+1) - 2)`이다.

## 3. 경우 (II): 모든 열이 채워짐 — `n ≥ 3` 가정

`n ≥ 3`이면 경우 (II) 배치의 열 그래프는 `n`-순환에서 연결되지 않은 인접쌍을
제거한 것이고, 순환에서 변 `k`개를 뺀 것이 연결일 필요충분조건은 `k ≤ 1`이다.
(이 단계는 정말로 `n ≥ 3`을 필요로 한다. `n = 2`에서 두 열은 인접쌍 둘이 아니라
하나로 이어져 있고, `n = 1`에서는 아예 없다. 그 두 경우는 §4에서 직접 확인한다.)
따라서

    g(n) = #{연결 안 된 인접쌍 0개} + #{정확히 1개}.

**0개인 경우.** 전이 유향그래프의 길이 `n` 닫힌 걷기의 수:

    각기둥:    tr(Mⁿ)        = 1 + Q_n        (고윳값 1, 1±√2)
    뫼비우스:  tr(Mⁿ P_σ)    = Q_n - 1
    엇각기둥:  tr(Mₐⁿ)       = L(2n)          (고윳값 0, (3±√5)/2)

뫼비우스의 대각합: `P_σ`는 `M`과 교환한다. `σ`-반대칭 고유벡터 `(1,-1,0)`
(`M`의 고윳값 `1`) 위에서 `P_σ`는 `-1`로 작용하고, `σ`-대칭 평면 위에서는 `+1`로
작용하며 그 위에서 `M`의 고윳값은 `1±√2`다. 그래서
`tr(Mⁿ P_σ) = (1+√2)ⁿ + (1-√2)ⁿ - 1 = Q_n - 1`이고 `tr(Mⁿ) = Q_n + 1`이다.
엇각기둥은 `n ≥ 1`에 대해 `tr(Mₐⁿ) = 0ⁿ + φ^{2n} + φ^{-2n} = L(2n)`이다.

**정확히 1개인 경우.** 배치를 그 유일한 미연결 인접쌍의 위치로 보내는 사상은 잘
정의되고, `n ≥ 3`이면 순환에는 서로 다른 인접쌍이 `n`개 있으므로 올이 그 부류를
같은 크기의 `n`개 블록으로 분할한다. (뫼비우스에서는 §2의 `σ`-변환이 블록 사이의
전단사를 주어 `n`개 위치가 모두 같은 개수를 갖는다.) 나쁜 인접쌍에서 잘라내면
블록은, `n-1`개의 내부 인접쌍이 모두 연결되고 순환 마디 쌍은 연결되지 않은
낱말 `w₁ … w_n`의 집합이 된다.

* **각기둥:** `{w₁, w_n} = {A,B}`, 즉 `2 (M^{n-1})_{A,B}`. `u_m = (Mᵐ)_{AA}`,
  `v_m = (Mᵐ)_{AB}`라 하면 `(1,-1,0)`이 `M`의 `1`-고유벡터이므로 모든 `m`에 대해
  `u_m - v_m = 1`이고, 또 `u_m + v_m = t_m`이다. 그래서 `v_m = (t_m - 1)/2`이고
  블록 크기는 `t_{n-1} - 1`이다.
* **뫼비우스:** 이음매가 연결됨 ⟺ `c_{n-1} ∩ σ(c_0) ≠ ∅`이므로 *미*연결은
  `{c_{n-1}, σ(c_0)} = {A,B}`, 즉 `(c_{n-1}, c_0) ∈ {(A,A), (B,B)}`이다. 블록
  크기는 `(M^{n-1})_{AA} + (M^{n-1})_{BB} = 2 u_{n-1} = t_{n-1} + 1`.
* **엇각기둥:** 미연결 순서쌍은 `(B,A)`뿐이므로 블록 크기는
  `(Mₐ^{n-1})_{A,B} = F(2n-2)`.

따라서 `n ≥ 3`에 대해

    각기둥:    g(n) = (Q_n + 1) + n (t_{n-1} - 1),
    뫼비우스:  g(n) = (Q_n - 1) + n (t_{n-1} + 1),                       (3)
    엇각기둥:  g(n) = L(2n)    + n F(2n-2).

## 4. 조립

경우 (I)과 (II)를 더한다. 각기둥과 뫼비우스에서는 `t_{n-1} = P_{n-1} + P_{n-2}`와
`P_{n+1} = 2P_n + P_{n-1}`을 써서

    P_{n+1} + t_{n-1} = 2P_n + 2P_{n-1} + P_{n-2} = 2P_n + P_n = 3 P_n.   (4)

**각기둥** (`n ≥ 3`):

    a(n) = n(P_{n+1} - 2) + (Q_n + 1) + n(t_{n-1} - 1)
         = Q_n + 3 n P_n - 3 n + 1 = A002203(n) + 3n·A000129(n) - 3n + 1.

**뫼비우스 사다리** (`n ≥ 3`):

    a(n) = n(P_{n+1} - 2) + (Q_n - 1) + n(t_{n-1} + 1)
         = Q_n + 3 n P_n - n - 1 = A002203(n) + 3n·A000129(n) - n - 1.

**엇각기둥** (`n ≥ 3`): `F(2n+1) = 2F(2n) - F(2n-2)`에서
`F(2n+1) + F(2n-2) = 2 F(2n)`이므로

    a(n) = n(F(2n+1) - 2) + L(2n) + n F(2n-2)
         = L(2n) + 2 n F(2n) - 2 n = A005248(n) - 2n + 2n·A001906(n).

**퇴화 경우 `n = 1, 2`** 는 §3이 적용되지 않으므로 같은 공식에 대해 직접 확인한다.

| | `n = 1` (`K₂`) | `n = 2` |
|---|---|---|
| 각기둥 | `3 = Q₁ + 3P₁ - 3 + 1` | `C₄`: `13 = Q₂ + 6P₂ - 6 + 1` |
| 뫼비우스 | `3 = Q₁ + 3P₁ - 1 - 1` | `K₄`: `15 = Q₂ + 6P₂ - 2 - 1` |
| 엇각기둥 | `3 = L(2) - 2 + 2F(2)` | `K₄`: `15 = L(4) - 4 + 4F(4)` |

(`K₂`의 연결 유도 비공집합 부분그래프는 `3`개, `C₄`는 `13`개, `K₄`는 완전그래프의
공집합 아닌 모든 부분집합이 연결이므로 `2⁴ - 1 = 15`개.) 그러므로 세 닫힌 형식은
**모든 `n ≥ 1`** 에서 성립한다. ∎

## 5. 추측된 점화식과 생성함수

`Q_n`과 `P_n`은 `x² - 2x - 1`로 소멸되므로 `n P_n`은 `(x² - 2x - 1)²`로 소멸되고,
아핀 부분 `-3n+1`과 `-n-1`은 `(x-1)²`로 소멸된다. `x²-2x-1`과 `x-1`은 서로소이므로
각기둥과 뫼비우스의 닫힌 형식은 모두

    (x-1)² (x²-2x-1)² = x⁶ - 6x⁵ + 11x⁴ - 4x³ - 5x² + 2x + 1

로 소멸된다. 이는 A286182와 A286185에 추측된 점화식
`a(n) = 6a(n-1) - 11a(n-2) + 4a(n-3) + 5a(n-4) - 2a(n-5) - a(n-6)`이며, OEIS가
명시한 대로 `n ≥ 7`에서 유효하다(`n = 6`에서는 조합적 값이 아닌 `a(0)`이 필요해
실패한다). 마찬가지로 `L(2n)`과 `F(2n)`은 `x² - 3x + 1`로 소멸되므로 엇각기둥의
닫힌 형식은

    (x-1)² (x²-3x+1)² = x⁶ - 8x⁵ + 24x⁴ - 34x³ + 24x² - 8x + 1

로 소멸되며, 이것이 A286183에 추측된 점화식이고 역시 `n ≥ 7`에서 유효하다.

닫힌 형식에 위 분모를 곱하면 각 항목에 추측된 분자가 남는다(그보다 높은 차수의
계수는 항등적으로 0이다).

    각기둥      x(3 - 5x + 6x² - 8x³ - 5x⁴ - 3x⁵) / ((1-x)²(1-2x-x²)²)
    뫼비우스    x(3 - 3x - 2x² - 4x³ + 3x⁴ - x⁵) / ((1-x)²(1-2x-x²)²)
    엇각기둥    x(3 - 9x + 12x² - 15x³ + 9x⁴ - 2x⁵) / ((1-x)²(1-3x+x²)²)

`1 - 3x + x² + x³ = (1-x)(1-2x-x²)`이므로 뫼비우스의 분자는 Robert Israel의
`(3x - 3x² - 2x³ - 4x⁴ + 3x⁵ - x⁶) / (1 - 3x + x² + x³)²`와 같다. ∎
