# 크리스털 성분의 유일성: 수학적 세부 사항

이 문서는 [README.ko.md](README.ko.md)의 논증을 자세히 적습니다. 각 단계마다
[`AgenticConjectures/CrystalComponentsUnique.lean`](../../AgenticConjectures/CrystalComponentsUnique.lean)에서
그 단계를 증명하는 Lean 선언의 이름을 밝힙니다. 8절은 컴퓨터 보조 증명입니다. 환원과 마지막 경우 분석은
Lean으로 확인하지만, 타원곡선의 정수점 목록은 Sage/PARI로 계산해 가정으로 넣습니다. 10절의 설명은
형식화되지 않았고 주장에도 포함되지 않습니다.

이 문서 전체에서 **크리스털**(`IsCrystalWithComponents n a b`)은 n이 홀수이고, a, b > 1이고, n = ab이며,
2(a + 1)(b + 1)이 (a + b)² + (ab + 1)²을 나눈다는 뜻입니다. 다음과 같이 씁니다.

D = (a + 1)(b + 1),  s = a + b,  u = (a + 1)/2,  v = (b + 1)/2.

## 1. 나눗셈 조건 (논문의 명제 1)

n + 1 = ab + 1 = D − s이고 D − 2s = (a − 1)(b − 1)이므로

(n + 1)² = s² + D(D − 2s) = s² + D(a − 1)(b − 1)  (1.1)

입니다. 따라서 s² + (n + 1)² = 2s² + D(a − 1)(b − 1)입니다. a가 홀수이면
(a − 1)(b − 1) = 2 · ((a − 1)/2)(b − 1)이므로 s² + (n + 1)² = 2(s² + D · ((a − 1)/2)(b − 1))이고, 2D가 이
값을 나눌 필요충분조건은 D ∣ s²입니다(`dvd_biharmonic_iff`, 가정: a 홀수). (1.1)에 의해
(n + 1)² ≡ s² (mod D)이므로 D ∣ s²은 D ∣ (n + 1)²과 동치입니다(`dvd_sq_add_iff_dvd_mul_add_one_sq`, 가정
없음).

크리스털에서는 n = ab가 홀수이므로 a와 b도 홀수입니다(`IsCrystalWithComponents.odd_left`,
`.odd_right`). 여기서 `isCrystal_iff_dvd_sq_add`와 `isCrystal_iff_dvd_succ_sq`가 나옵니다. 논문의 기호로
이것은 명제 1의 동치 B ∈ ℕ ⟺ Q ∈ ℕ ⟺ F ∈ ℕ이며, 여기서 Q = s²/D, F = (n + 1)²/D입니다. 아직 열려 있는
Formal Conjectures PR #7051은 같은 동치와 논문의 네 번째 양 P = s(n + 1)/D에 대한 동치까지 증명하고, 논문
3절의 점화식 특성화는 TODO로 남겨 둡니다.

## 2. (u, v) 형태와 불변량 k

크리스털에서는 a, b ≥ 3이므로 u, v ≥ 2입니다. a + 1 = 2u, b + 1 = 2v이므로 D = 4uv, s = 2(u + v − 1)이고,
따라서 D ∣ s²은 uv ∣ (u + v − 1)²과 동치입니다(`isCrystal_iff_uv_dvd`).

**분리.** uv ∣ (u + v − 1)² ⟺ u ∣ (v − 1)²이고 v ∣ (u − 1)²입니다(비공개 보조정리 `int_uv`에서 ℤ 위에서
증명, `isCrystal_iff_uv`).

- (⇒) (u + v − 1)² ≡ (v − 1)² (mod u)이고 (u + v − 1)² ≡ (u − 1)² (mod v)입니다.
- (⇐) g = gcd(u, v)라 하면 g ∣ (v − 1)² = v(v − 2) + 1이고 g ∣ v이므로 g = 1입니다. 서로소인 u와 v가 모두
  (u + v − 1)²을 나누므로 uv도 이를 나눕니다.

특히 모든 크리스털에서 gcd(a + 1, b + 1) = 2입니다.

**불변량.** k = s²/D = (u + v − 1)²/(uv)로 둡니다. 이는 논문의 Q(a, b)입니다. Lean은 `crystalK a b`를
내림하는 ℕ 나눗셈으로 정의하는데, 크리스털에서는 이 나눗셈이 정확합니다
(`IsCrystalWithComponents.sq_add_eq`). D = n + 1 + s이므로

s² = k(n + 1 + s)  (`IsCrystalWithComponents.sq_add_eq_mul`)  (2.1)

입니다.

**k ≥ 3** (`IsCrystalWithComponents.three_le_crystalK`): u, v ≥ 2이면
(u + v − 1)² − 2uv = (u − 1)² + (v − 1)² − 1 ≥ 1이므로 kuv > 2uv입니다.

## 3. 환원: n과 k가 크리스털을 결정한다

n과 k ≥ 1을 고정합니다. (2.1)에 의해 s는 z² − kz − k(n + 1)의 양의 근입니다. 두 근의 곱이
−k(n + 1) < 0이므로 양의 근은 정확히 하나이고, 따라서 s가 결정됩니다. 그러면 a와 b는 z² − sz + n의 두
근입니다. 따라서 n과 k가 같은 두 크리스털 분해는 비순서쌍으로서 같습니다(`eq_of_crystalK_eq`).

결과적으로 추측은 *같은 n의 두 크리스털 분해는 항상 같은 k를 갖는다*는 명제와 동치입니다
(`statement_iff_crystalK_eq`). 반대 방향은 같은 비순서쌍이 같은 k를 갖는다는 사실(`crystalK_comm`)에서
나옵니다.

## 4. 비에타 하강 (논문의 정리 4)

정수 w에 대해 u₀ = 0, u₁ = 1, u_{m+2} = (w − 2)u_{m+1} − u_m + 2로 둡니다(`seqU w`).
Q_w(x, y) = (x + y − 1)² − wxy라 쓰면, y를 고정했을 때

Q_w(x, y) = x² − ((w − 2)y + 2)x + (y − 1)²

은 x에 대한 최고차항 계수 1인 이차식입니다. x가 근이면 다른 근은 x′ = (w − 2)y + 2 − x이고
xx′ = (y − 1)²입니다.

**불변식** (`seqU_invariant`): 모든 m에 대해 Q_w(u_{m+1}, u_m) = 0입니다. 기저: Q_w(1, 0) = 0.
단계: Q_w(u_{m+1}, u_m) = 0이면 u_m은 Q_w(·, u_{m+1})의 근이고, 그 짝
(w − 2)u_{m+1} + 2 − u_m = u_{m+2}도 근입니다.

**정리 4** (`sq_eq_mul_iff_seqU`): 임의의 정수 w와 양의 정수 x, y에 대해 Q_w(x, y) = 0일 필요충분조건은
어떤 m ≥ 0에 대해 (x, y) = (u_{m+2}, u_{m+1}) 또는 (x, y) = (u_{m+1}, u_{m+2})인 것입니다.

- (⇐) 불변식과 Q_w의 대칭성에서 나옵니다.
- (⇒) x + y에 대한 강한 귀납법입니다(비공개 보조정리 `seqU_descent`). 대칭성에 의해 x ≥ y라 둡니다.
  - y = 1이면 x² = wx이므로 x = w이고 (x, y) = (u₂, u₁)입니다.
  - y ≥ 2이면 x의 짝 x′ = (w − 2)y + 2 − x = (y − 1)²/x는 0 < x′ < y²/x ≤ y인 정수입니다. 따라서
    (x′, y)는 합이 더 작은 양의 해이고, 귀납 가정에 의해 연속한 두 항의 쌍입니다.
    (y, x′) = (u_{m+2}, u_{m+1})이면 x = (w − 2)y + 2 − x′ = u_{m+3}입니다.
    (y, x′) = (u_{m+1}, u_{m+2})이면 x = (w − 2)u_{m+1} + 2 − u_{m+2} = u_m인데, x > 0 = u₀이므로 m ≥ 1이고,
    (x, y) = (u_m, u_{m+1})은 역시 연속한 두 항입니다.

논문은 참고문헌 [1] (Abrate, Barbero, Cerruti, Murru, *Polynomial sequences on quadratic curves*,
Integers, 2015)을 인용해 정리 4를 n ≥ 1에 대해 (x, y) = (u_n(w), u_{n−1}(w))로 씁니다. 이 형태는 쌍의 순서를
고정하고, 그 첨자 범위에는 양이 아닌 쌍 (u₁, u₀) = (1, 0)이 들어갑니다. Lean 명제는 두 순서를 모두
허용하고 쌍 (u₁, u₂) = (1, w)에서 시작합니다.

## 5. 분류 (논문의 정리 5)

k = `crystalK a b`인 크리스털에서 (u, v)는 Q_k = 0의 양의 해이므로(2절), 수열 `seqU k`에 대해
{u, v} = {u_{m+1}, u_{m+2}}입니다(`IsCrystalWithComponents.exists_seqU`). 역으로 어떤 정수 w에 대해
2 ≤ u_{m+1}, 2 ≤ u_{m+2}이고 {a + 1, b + 1} = {2u_{m+1}, 2u_{m+2}}이면, a와 b는 3 이상의 홀수이고 uv가
(u + v − 1)² = wuv를 나누므로 n = ab는 크리스털입니다(`isCrystal_iff_seqU`).

**사슬.** k ≥ 3에 대해 w_j = u_{j+1}로 둡니다. 즉 w₀ = 1, w₁ = k, w₂ = (k − 1)², w₃ = k(k − 2)²이고
w_{j+1} = (k − 2)w_j − w_{j−1} + 2입니다. **k의 j번째 크리스털**(j ≥ 1)은
{a, b} = {2w_j − 1, 2w_{j+1} − 1}이고, 그 곱을 n_j(k)로 씁니다.

- k ≥ 4이면 사슬은 순증가합니다. w_{j+1} − w_j = (k − 3)w_j − w_{j−1} + 2 ≥ w_j − w_{j−1} + 2이므로
  귀납적으로 w_{j+1} − w_j ≥ 2입니다. 따라서 n_j(k)는 j에 대해 순증가하고, j가 다르면 크리스털도
  다릅니다.
- k = 3이면 사슬은 주기 4인 1, 3, 4, 3, 1, 3, 4, …입니다. 두 항이 모두 2 이상인 쌍은 (3, 4)와 (4, 3)뿐이므로
  k = 3은 크리스털 {5, 7} 하나만 줍니다(`IsCrystalWithComponents.eq_five_seven_of_crystalK_eq_three`).

크리스털은 k를 결정하므로 정확히 하나의 사슬 위에, (k ≥ 4이면) 정확히 하나의 위치 j에 놓입니다.

## 6. 뤼카 수열을 통한 닫힌 형태

L₀ = 0, L₁ = 1, L_{i+2} = cL_{i+1} − L_i로 둡니다(`lucas c`). 이차형식 x² − cxy + y²은
(x, y) ↦ (cx − y, x)에 대해 불변이므로

L_{i+1}² − cL_iL_{i+1} + L_i² = 1  (`lucas_cassini`)  (6.1)

이고, c ≥ 2이면 0 ≤ L_i < L_{i+1}입니다(`lucas_nonneg_lt`). c = k − 2로 두고 두 점화식과 (6.1)을 써서
i에 대해 귀납하면

u_{2i} = kL_i²,  u_{2i+1} = (L_i + L_{i+1})²  (`seqU_lucas`)

를 얻습니다.

p, r ≥ 0에 대해 (p + r)² − kpr = p² − (k − 2)pr + r²이므로, (6.1)은 연속한 두 항에 대해
(p + r)² = kpr + 1이라는 뜻입니다. 따라서 k의 j번째 크리스털은

{a + 1, b + 1} = {2kp², 2(p + r)²}이고, j = 2i − 1이면 (p, r) = (L_i, L_{i+1}), j = 2i이면 (p, r) = (L_{i+1}, L_i)

입니다.

`isCrystal_iff_kpr`은 분류를 이 형태로 씁니다. n = ab가 크리스털일 필요충분조건은 어떤 k와
(p + r)² = kpr + 1을 만족하는 어떤 p, r ≥ 1에 대해 {a + 1, b + 1} = {2kp², 2(p + r)²}인 것이며, 이때
k = `crystalK a b`입니다(`crystalK_eq_of_kpr`). k ≤ 2이면 (p + r)² − kpr − 1 ≥ p² + r² − 1 > 0이므로, 이런
p, r이 있으면 k ≥ 3입니다.

**pronic 형태.** m = p(p + r)로 두면 u + v − 1 = kp² + kpr = km이고 uv = km²이므로 s = 2km, D = 4km²이고

n + 1 = D − s = 2km(2m − 1)  (6.2)

입니다. q = 2m − 1로 두면 이는 n + 1 = kq(q + 1), a + b = k(q + 1)이 됩니다. 역으로 이 두 식에서
D = n + 1 + s = k(q + 1)²과 s² = kD가 나오므로, `isCrystal_iff_pronic`은 이 두 식으로 크리스털을
특성화합니다.

## 7. Lean으로 증명한 경우

**7.1 같은 k.** 3절(`eq_of_crystalK_eq`).

**7.2 k = 3.** k = 3인 크리스털은 {5, 7}뿐입니다(5절). 두 인수가 모두 1보다 큰 35의 분해는 5 · 7뿐입니다
(`IsCrystalWithComponents.eq_five_seven_of_eq_35`). 따라서 n이 같은 두 크리스털 중 하나의 k가 3이면
n = 35이고 둘 다 {5, 7}입니다(`eq_of_crystalK_eq_three`).

**7.3 k = 4 족** (`IsCrystalWithComponents.crystalK_eq_four_iff`). c = 2이면 L_i = i이므로
{u, v} = {(2i)², (2i + 1)²} 또는 {(2i + 2)², (2i + 1)²}입니다. 즉 k = 4의 j번째 크리스털은 t = j + 1 ≥ 2에
대해 {u, v} = {t², (t + 1)²}입니다. 이때 n = f₄(t) = (2t² − 1)(2(t + 1)² − 1)이고, X = t(t + 1)로 두면
f₄(t) + 1 = 4X(X − 1)입니다.

**7.4 j = 1 족.** a + 1 = 2k이면 b + 1 = 2(k − 1)²입니다(`IsCrystalWithComponents.j1`). u = k이면 방정식
(k + v − 1)² = k²v에서 v는 제곱수 c²이어야 하고, c² − kc + (k − 1) = (c − 1)(c − k + 1) = 0인데 v ≥ 2이므로
c = 1은 제외됩니다. 따라서 크리스털은 {2k − 1, 2(k − 1)² − 1}이고

n = f₁(k) = (2k − 1)(2(k − 1)² − 1),  f₁(k) + 1 = 2k(k − 1)(2k − 3)

입니다. f₁은 k ≥ 2에서 순증가하므로 n이 같은 두 크리스털은 k도 같고, 7.1에 의해 일치합니다(`eq_of_j1`).
이들이 j = 1 크리스털입니다. k = 3이면 {5, 7}, k = 4이면 {7, 17}(7.3의 t = 2 원소), k ≥ 5이면 아래의
부류 F1입니다.

## 8. k = 4 대 j = 1 (컴퓨터 보조 증명; 정수점을 가정한 Lean 증명)

**주장.** 정수 t ≥ 2, K ≥ 3이 f₄(t) = f₁(K)를 만족하면 (t, K) = (2, 4)이며, 이때 n = 119 = 7 · 17은 7.3과
7.4에 동시에 속하는 k = 4인 크리스털 하나입니다. 따라서 k = 4 족의 크리스털은 k가 다른 j = 1 족의
크리스털과 n을 공유하지 않습니다.

**타원곡선으로의 환원.** 7.3과 7.4에 의해 f₄(t) = f₁(K)는 2X(X − 1) = K(K − 1)(2K − 3), 즉

(2X − 1)² = 4K³ − 10K² + 6K + 1,  X = t(t + 1)

과 동치입니다. 양변에 16을 곱하고 x = 4K, y = 4(2X − 1)로 두면

E: y² = x³ − 10x² + 24x + 16

의 정수점 중 4 ∣ x이고 y ≡ 4 (mod 8)인 점이 됩니다. E의 conductor는 2432 = 2⁷ · 19이고 꼬임 부분군은
자명합니다. [`ec_k4_j1.py`](ec_k4_j1.py)는 다음 단계를 수행하고 각 결과를 assert로 확인하며, 그 출력은
[`logs/ec_k4_j1.log`](logs/ec_k4_j1.log)에 있습니다.

1. **랭크.** PARI `ellrank`는 [r, R, s, L] = [2, 2, 0, [(0, 4), (4, 4)]]를 돌려줍니다. 랭크의 하계와 상계가
   같으므로 E(ℚ)의 랭크는 2이고, P₁ = (0, 4), P₂ = (4, 4)는 독립입니다.
2. **생성원.** ν를 ⟨P₁, P₂⟩의 E(ℚ) ≅ ℤ² 안에서의 지수라 하면 Reg(P₁, P₂) = ν² Reg(E(ℚ))입니다. λ를
   무한 위수인 모든 점의 표준 높이(canonical height) ĥ의 하계라 합시다. 랭크 2인 격자 (E(ℚ), ĥ)에 대한
   에르미트(Hermite) 부등식은 γ₂² = 4/3으로 λ ≤ γ₂ Reg(E(ℚ))^{1/2}를 주므로
   ν ≤ (Reg(P₁, P₂) · 4/3)^{1/2} / λ입니다.
   Sage의 `E.height_function().min(0.0001, 5)`(Cremona–Siksek과 Thongjunthug의 방법으로, 하계를 엄밀하게
   확립합니다)는 λ = 0.0953418…을 주고, Reg(P₁, P₂) = 0.2418772…이므로 ν ≤ 5.956, 즉 ν ≤ 5입니다.
   PARI `ellsaturation([P₁, P₂], 100)`은 ⟨P₁, P₂⟩를 포함하고 E(ℚ) 안에서의 지수가 100 이하의 소인수를 갖지
   않는 부분군의 생성원을 돌려줍니다. 결과는 [(4, 4), (0, −4)] = [P₂, −P₁]이고 regulator가 같으므로, ν 자체가
   100 이하의 소인수를 갖지 않습니다. ν ≤ 5와 합치면 ν = 1, 즉 P₁과 P₂가 E(ℚ)를 생성합니다. 하계 λ와
   regulator는 같은 정규화를 씁니다. 예를 들어 ĥ(P₂) = 0.374… ≥ λ입니다.
3. **정수점.** Sage의 `E.integral_points(mw_base=[P₂, −P₁])`(타원 로그, Baker 형 상계, 격자 축소)는 y의
   부호를 무시하고 다음 점들을 돌려줍니다.
   (0, 4), (3, 5), (4, 4), (6, 4), (10, 16), (16, 44), (19, 61), (84, 724), (1200, 41396).
4. **(K, X, t)로 되돌리기.** 4 ∣ x이고 y/4가 홀수인 점에서 K = x/4, X = (y/4 + 1)/2를 얻습니다.

| 점 | K | X | 4X + 1 | X = t(t + 1)인 t |
| --- | ---: | ---: | ---: | --- |
| (0, ±4) | 0 | 1, 0 | 5, 1 | 없음; t = 0 |
| (4, ±4) | 1 | 1, 0 | 5, 1 | 없음; t = 0 |
| (16, ±44) | 4 | 6, −5 | 25, −19 | t = 2; 없음 |
| (84, ±724) | 21 | 91, −90 | 365, −359 | 없음 |
| (1200, ±41396) | 300 | 5175, −5174 | 20701, −20695 | 없음 |

정수 t에 대해 X = t(t + 1)일 필요충분조건은 4X + 1이 완전제곱수인 것입니다. t ≥ 2, K ≥ 3인 해는
(t, K) = (2, 4)뿐입니다. 논증의 일부가 아닌 확인 작업으로, 스크립트는 0 ≤ K ≤ 10⁶에서
4K³ − 10K² + 6K + 1이 제곱수인 K를 직접 찾아 정확히 K ∈ {0, 1, 4, 21, 300}을 얻습니다.

**Lean에서.** `eq_of_crystalK_eq_four_of_j1`은 "n이 같은 k = 4인 크리스털과 j = 1인 크리스털은
일치한다"는 형태로 위 주장을 증명하며, 가정 `EllipticCurveIntegralPoints`를 씁니다. 이 가정은 E의 모든
정수점이 x ∈ {0, 3, 4, 6, 10, 16, 19, 84, 1200}, 즉 3단계의 x좌표 중 하나를 갖는다는 명제입니다. E로의
환원과 4단계는 Lean이 확인합니다. K = 21과 K = 300이면 증명은 (2X − 1)² − 181²과 (2X − 1)² − 10349²을
인수분해하고 t의 범위를 제한하며, K = 4이면 두 크리스털의 k가 같으므로 7.1에 의해 일치합니다. 가정을
확립하는 1–3단계는 Lean으로 확인하지 않았습니다.

**신뢰 범위.** 이 가정은 PARI 2.17.4(`ellrank`, `ellsaturation`)와 Sage(passagemath 10.8.13: 높이 하계와
`integral_points`)에 의존합니다. 그중 어느 것도 형식적으로 검증되지 않았습니다.

## 9. 탐색: 알고리즘과 완전성

**부류.** 모든 크리스털은 정확히 한 부류에 속합니다(5절).

| 부류 | 정의 | n |
| --- | --- | --- |
| F3 | k = 3 | 35 |
| F4 | k = 4 | f₄(t), t ≥ 2 |
| F1 | k ≥ 5, j = 1 | f₁(k) |
| S | k ≥ 5, j ≥ 2 | n_j(k) |

f₁(k ≥ 2)과 f₄(t ≥ 1)는 순증가하므로 F1과 F1, F4와 F4는 충돌할 수 없고(`eq_of_j1`과 `eq_of_crystalK_eq`로도
증명됨), F3과 다른 모든 부류는 `eq_of_crystalK_eq_three`가 다룹니다. 탐색은 S를 S, F1, F4, F3과 비교하고,
F4를 F1, F3과 비교합니다. 마지막 비교는 8절이 있으므로 중복이며 점검용입니다.

**S의 크기.** k의 j = 2 원소는 {u, v} = {(k − 1)², k(k − 2)²}이므로
n₂(k) = (2(k − 1)² − 1)(2k(k − 2)² − 1) ≈ 4k⁵이고, 일반적으로 n_j(k) ≈ 4k^{2j+1}입니다. 따라서 X 이하의 S에는
k ≲ (X/4)^{1/5}만 기여하며, 2¹²⁷ − 1 이하에서 S의 원소는 33,811,278개로 F1의 약 3.5 · 10¹²개에 비해 훨씬
적습니다.

**S 나열의 완전성.** [`crystal_search.c`](crystal_search.c)(A)와 [`crystal_exact.py`](crystal_exact.py)(B)는
모두 k = 5, 6, …에 대해, 각 k마다 j = 2, 3, …에 대해 반복합니다.

1. k ≥ 5를 고정하면 n_j(k)는 j에 대해 순증가하므로(5절) X 이하의 원소는 j = 2, …, J(k)이고, X를 넘는 첫
   원소에서 멈춰도 빠지는 것이 없습니다.
2. n₂(k)는 k에 대해 순증가하므로, n₂(k) > X가 되면 그보다 큰 k는 X 이하의 S 원소를 갖지 않습니다. 두
   프로그램 모두 X 이하의 S 원소가 없는 첫 k에서 멈춥니다.
3. A는 뤼카 쌍으로 사슬을 생성하고(6절. (L_i, L_{i+1})이면 j = 2i − 1, (L_{i+1}, L_i)이면 j = 2i), 나열하는
   모든 원소에 대해 (p + r)² = kpr + 1을 확인합니다. B는 점화식 w_{j+1} = (k − 2)w_j − w_{j−1} + 2로
   사슬을 생성하고, 모든 원소에 대해 (a + b)² = k(a + 1)(b + 1)을, 각 k의 처음 두 원소에 대해서는 원래
   정의를 확인합니다. 두 프로그램 모두 각 사슬에서 n이 증가하는지 확인합니다.

**충돌 검사.**

- S 대 S: S의 원소를 정렬하고 이웃한 원소를 비교합니다.
- S 대 F1, F4: 각 원소 n에 대해 f₁(K) ≤ n인 가장 큰 K ≥ 3을 찾고 K ≥ 5에서 f₁(K) = n인지 검사합니다. f₄와
  t ≥ 2에 대해서도 같습니다. 탐색은 추정값(A는 부동소수점, B는 정수 거듭제곱근)에서 시작해 f₁ 또는 f₄의
  정확한 값을 비교하며 정답까지 한 칸씩 이동하므로, 추정값은 이동 횟수에만 영향을 줍니다.
- S 대 F3: n = 35인지 검사합니다.
- F4 대 F1, F3: f₄(t) ≤ X인 모든 t ≥ 2(A), 또는 `--f4-limit`로 준 상한까지(B) 검사합니다.

F1과 F4의 크기는 X에서 f₁과 f₄를 역산해 얻습니다.

**오버플로.** A는 128비트 정수를 쓰며 모든 곱과 합이 포화됩니다. 즉 오버플로가 나면 2¹²⁸ − 1을
돌려줍니다. X ≤ 2¹²⁷ − 1이므로 포화된 값은 X보다 커서 나열되지 않고, 나열된 값과 같아지지도 않습니다.
2x − 1의 뺄셈은 짝수 값에만 적용되는데, 짝수는 홀수 2¹²⁸ − 1과 같을 수 없으므로 포화된 값은 계속 포화된
상태로 남습니다. B는 Python의 정확한 정수를 씁니다.

**독립성.** A와 B는 공유하는 코드가 없습니다. 사슬 생성 방법(뤼카 쌍 대 (u, v) 점화식), f₁과 f₄의 역산
방법(부동소수점 대 정수 거듭제곱근), 산술(포화 128비트 대 정확한 정수)이 모두 다릅니다. 두 프로그램 모두
완전성은 Lean 분류에 의존합니다.

**직접 검사.** [`direct_check.py`](direct_check.py)는 분류를 쓰지 않습니다. `isCrystal_iff_uv`에 의해 a ≤ b인
크리스털은 u ≤ v, v ∣ (u − 1)², (2u − 1)² ≤ ab ≤ X를 만족합니다. 이런 u마다 최소 소인수 체로 u − 1을
소인수분해해 (2u − 1)(2v − 1) ≤ X인 (u − 1)²의 약수 v ≥ u를 나열하고 원래 정의를 검사합니다. 상한을 넘는
부분곱은 잘라 내는데, 상한 이하인 약수의 부분곱은 모두 상한 이하이므로 이 가지치기는 안전합니다. 그다음
x ≤ y에 대한 하강 (x, y) ↦ ((x − 1)²/y, x)로 k와 사슬 위치 j를 계산하며, 이 하강은 쌍 (1, k)에서 끝납니다.
이 프로그램은 10¹² 이하에서 7,266개, 10¹⁴ 이하에서 32,094개로 A, B와 같은 크리스털을 찾고, 부류별 크기와
S 체크섬도 같습니다. 분류가 어떤 크리스털을 놓쳤다면 직접 검사가 A와 B보다 많은 크리스털을 찾았을
것입니다.

**체크섬.** 세 프로그램 모두 S 원소의 합을 2⁶⁴로 나눈 나머지를 출력합니다.

## 10. 미해결 경우에 대한 설명 (형식화되지 않았고 주장하지 않음)

남은 미해결 부분은 부류 S의 크리스털이 k가 다른 크리스털과 n을 공유하는 경우입니다. 아래 설명은 증명이
넘어야 할 어려움을 보여 줍니다.

**10.1 m ≥ k − 1.** 6절의 기호에서 kpr = (p + r)² − 1을 써서 전개하면

pr(m + 1 − k) = (p² − 1)(pr + r² − 1)

입니다. 따라서 m ≥ k − 1이고, 등호는 p = 1일 때만 성립하며 k ≥ 4에서 이는 j = 1 크리스털입니다. (6.2)에
의해 n + 1 = 2km(2m − 1)은 k와 m에 대해 증가합니다. (k, m)인 크리스털이 k′ ≠ k의 j = 1 크리스털(이것의
m은 k′ − 1)과 n을 공유한다고 합시다. k > k′이면 m ≥ k − 1 ≥ k′ > k′ − 1이 되어 n이 더 커지므로 k < k′이고,
그러면 m > k′ − 1입니다. 즉 상대 크리스털은 k가 더 작고 m이 더 큽니다.

**10.2 m(m − 1)의 분해에 의한 매개화.** X = u − m, Y = v − m으로 두면 X = p(p² + pr − 1)/r ≥ 1,
Y = r(p + r) ≥ 1, XY = m(m − 1), X + Y = (k − 2)m + 1이고

n + 1 = 2(2m − 1)(2m − 1 + X + Y)

입니다. 역으로 m ≥ 2와 XY = m(m − 1), X + Y ≡ 1 (mod m)을 만족하는 양의 X, Y에 대해, 쌍
(u, v) = (m + X, m + Y)는 k = 2 + (X + Y − 1)/m인 크리스털 쌍입니다. 실제로 uv = m(2m − 1 + X + Y) = km²이고
u + v − 1 = km입니다. j = 1 크리스털은 정확히 {X, Y} = {1, m(m − 1)}인 경우입니다. 따라서 크리스털은
pronic 수 m(m − 1)을 합이 m을 법으로 1인 두 인수로 분해하는 방법에 대응하고, 추측은
(2m − 1)(2m − 1 + X + Y)가 m을 결정한다는 명제입니다.

**10.3 국소적 장애가 없음.** k = 0이면 사슬은 1, 0, 1, 0, …이므로 모든 j에 대해 n_j(0) = −1입니다. 또
f₁(1) = f₁(0) = −1, f₄(0) = f₄(−1) = −1입니다. 따라서 두 족 사이의 방정식 n_j(k) = n_{j′}(k′)이나
n_j(k) = f₄(t)는 모두 정수해를 가지며, 그러므로 모든 법에 대해, 그리고 ℝ에서 해를 갖습니다. 즉 합동식이나
부호에 의한 논증으로는 두 족 사이의 충돌을 배제할 수 없습니다. 같은 이유로 M′ ≥ 2이면 n mod M은 결코
k mod M′을 결정하지 않습니다. K ≡ 0과 K ≡ 1 (mod MM′)인 F1 크리스털은 모두 n ≡ −1 (mod M)이기 때문입니다.
10¹⁶ 미만의 크리스털 144,251개를 조사해 M ∈ {2, 3, 4, 5, 7, 8, 9, 16, 24, 32, 48, 64, 72, 96, 128, 144},
M′ ∈ {2, 3, 4, 5, 7, 8, 9, 16}에 대해 이를 확인했습니다.

**10.4 종수.** 충돌 방정식은 가장 작은 족의 쌍에서부터 이미 종수가 1보다 큰 곡선입니다. sympy로 계산한
리만-후르비츠(Riemann–Hurwitz) 공식에 따르면 다음과 같습니다.

- F1 대 j = 2 원소, k(k − 1)(2k − 3) = k′(k′ − 1)(k′ − 2)(2k′² − 6k′ + 3): 종수 4.
- F4 대 j = 2 원소, X = t(t + 1)에 대해 2X(X − 1) = k′(k′ − 1)(k′ − 2)(2k′² − 6k′ + 3): 종수 6.
- 변수 (K, t)에서 F4 대 F1: 종수 3. t ↦ −1 − t에 의한 몫은 8절의 곡선 E입니다.

이런 곡선은 각각 정수점이 유한개입니다(Siegel). 그러나 S는 무한히 많은 족(j ≥ 2마다 하나씩)으로 이루어져
있으므로, 증명에는 j에 대해 균일한 논증이 필요합니다.

**10.5 휴리스틱.** 단순한 무작위 모형에서 S의 원소 근처의 홀수 n이 F1에 속할 확률은 f₁(K) ≈ n인 K에 대해
약 2/f₁′(K) ≈ (1/6)(n/4)^{−2/3}이고, F4에 속할 확률은 약 2/f₄′(t) ≈ (1/8)(n/4)^{−3/4}입니다. S의 원소 전체에
대해 더하면 이 모형은 F1과의 충돌을 약 0.006개, F4와의 충돌을 약 0.002개 예측하며, 거의 전부가 가장 작은
원소들에서 나옵니다. 가장 작은 10개(모두 4 · 10⁵ 미만)가 각각 0.005와 0.002를 차지합니다. 2¹²⁷ − 1보다 큰
범위에서는 약 2 · 10⁻¹⁹개를 예측하며, 거의 전부가 k > 3.36 · 10⁷인 j = 2 원소에서 나옵니다. 그 값은 약
Σ_{k>k₀} (1/6)k^{−10/3} ≈ (1/14)k₀^{−7/3}입니다. 이 모형은 산술적 상관관계를 무시하므로(예를 들어 F1의
원소는 모두 4를 법으로 3이지만 S의 원소는 그렇지 않을 수 있습니다), 반례가 있더라도 클 가능성은 낮다는
것만 시사합니다. 증명에 필요한 종류의 증거는 아닙니다.
