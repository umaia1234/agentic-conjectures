# 세타 산술합: 정확한 공식, 상계, 그리고 2·10⁶까지의 검증

정수 $h,k\ge1$에 대해 다음과 같이 둡니다.

\[
S'(h,k)=\sum_{j=1}^{k-1}(-1)^{j+1+\lfloor hj/k\rfloor},\qquad
S(k)=\sum_{h=1}^{k-1}S'(h,k).
\]

B. C. Berndt, R. N. Bhat, J. L. Meyer, L. Xie, A. Zaharescu의 논문 *An arithmetic sum
associated with the classical theta function*([arXiv:2501.03234](https://arxiv.org/abs/2501.03234);
Results Math. 81, no. 1, [doi:10.1007/s00025-025-02584-2](https://doi.org/10.1007/s00025-025-02584-2))는
$S'(h,k)$를 $S(h,k)$로 쓰며, 이 합은 Berndt의 Hardy 합 가운데 하나입니다. 논문의 주된
추측(arXiv v1의 추측 1.1)은 다음과 같습니다.

> “If $k$ is an odd prime, then $S(k)>0$.”

즉 $k$가 홀수 소수이면 $S(k)>0$이라는 주장입니다. 업스트림 형식화는 추측 4.1–4.4(v1
번호)도 함께 진술합니다. 홀수 소수 $k$에 대해 $k>5$이면 $S(k)>k$, $k>233$이면
$S(k)>2k$, $k>3119$이면 $S(k)>3k$이고, 모든 $n$에 대해 충분히 큰 모든 $k$에서
$S(k)>nk$라는 것입니다. 추측 3.3은 arXiv v2에 처음 나오며, v3(4쪽)의 문장도 같습니다.
v1을 따르는 업스트림 파일에는 없습니다.

> “Let $C_1$ and $C_2$ be any fixed positive numbers. Let $\epsilon>0$ be fixed. Then, for all
> primes $k$ sufficiently large, $C_1k<S(k)<C_2k^{1+\epsilon}$.”

즉 모든 $C_1,C_2>0$과 모든 $\varepsilon>0$에 대해, 충분히 큰 모든 소수 $k$에서 두 부등식이
모두 성립해야 합니다. $C_1$이 임의이므로 첫 번째 부등식은 추측 4.4와 동치입니다(Lean:
`statement_3_3_lower_iff`).

## 판정

**부분 결과(partial).** 다섯 업스트림 추측 가운데 해결된 것은 없으며, 추측 3.3은 두 번째
부등식만 손으로 증명했습니다. 이 디렉터리가 더하는 것은 세 가지입니다.

1. **Lean(커널 검증).**
   - 소수 $k$에 대한 $S(k)$의 정확한 환원식.
   - 모든 홀수 소수 $k$에 대한 정확한 공식 $S(k)=kH(k)-\tfrac{k-1}2+2V(k)$
     ([DETAILS.ko.md](DETAILS.ko.md)의 정리 4.3). 여기서
     $H(k)=\sum_{v\text{ odd},\,v\le k-2}1/v$이므로 $kH(k)=\tfrac12k\ln k+O(k)$이고,
     $V(k)$는 Hardy 합들의 합입니다. 모든 추측은 $V(k)$의 하계 문제가 되며, 추측 1.1에
     대해서는 Lean이 그 동치를 증명합니다.
   - $k<300$인 모든 홀수 소수에 대한 추측 1.1, 4.1, 4.2.
   - 추측 3.3의 진술과, 그것이 두 부등식의 연언이며 첫 번째 부등식이 추측 4.4와 동치라는
     증명. 어느 부등식도 Lean으로 증명하지는 않았습니다.
2. **수학(손으로 쓴 증명이며 기계 검증되지 않았습니다).** [DETAILS.ko.md](DETAILS.ko.md)를
   보십시오.
   - 논문 하계의 정확한 오차항(명제 5.1)과 정확한 약수 항(명제 6.1).
   - 모든 홀수 소수 $k$에 대한 무조건적 상계 $|S(k)|<6k(1+\ln k)^2+8k$(정리 7.1). 이
     상계는 추측 3.3의 두 번째 부등식을 증명합니다.
   - $S(k)$의 지표합 표현(명제 8.1).

   이 증명들은 어느 것도 형식화하지 않았습니다. 정리 7.1은 독립적으로 검토되었습니다. 별도의
   AI 검토가 모든 단계를 다시 유도했고 빈틈을 찾지 못했습니다. CI는 수치만 다시 검사합니다.
   `verify.py`는 $k\le400$인 모든 소수에 대해 정리 7.1의 각 단계를, 표의 모든 행에 대해
   상계를, 그리고 나머지 항등식을 작은 범위에서 검사합니다.
3. **계산.** 서로 다른 두 $O(k\log k)$ 알고리즘으로 $k\le2\cdot10^6$인 모든 홀수 소수에서
   $S(k)$를 계산했고, 두 결과는 모든 곳에서 일치합니다. 정의를 그대로 계산하는 방법으로도
   $k\le30000$인 모든 소수와 $k\le10000$인 모든 $k$를 계산했습니다.
   $k\le2\cdot10^6$인 홀수 소수 가운데 추측 1.1, 4.1, 4.2, 4.3을 위반하는 것은 없습니다.

출판된 추측의 일부를 해결하는 진술은 이 상계 하나뿐입니다. 그 증명은 Dedekind 합에 관한
고전적 사실을 쓰며(DETAILS 7절) 기계 검증되지 않았습니다. Lean은 이 부등식을
(`statement_3_3_upper`) 진술하지만 증명하지는 않습니다. 이 상계가 진술된 문헌은 보지
못했지만, 새로움을 주장하는 것은 아닙니다.

## 원 진술과 선행 연구 확인

- **논문.** arXiv v1(2024년 12월 10일), v2(2025년 12월 2일), v3(2026년 1월 9일). v2와 v3의
  본문은 arXiv 도장만 다릅니다. 여기서는 v1과 v3의 번호를 쓰며, 업스트림 파일은 v1을
  따릅니다. 학술지 판은 확인하지 않았으며 번호가 다를 수 있습니다. 논문은 $S'(h,k)$와
  $S(k)$의 초등적 성질을 증명하며, 그중에는 홀수 $h$와 소수 $k$에 대한 $S'(h,k)=0$(v1
  보조정리 5.7, v3 명제 7.5)이 있습니다. 또한 큰 $k$에서는 음수가 되는 하계(v1 정리 6.4,
  v3 정리 6.3)를 증명합니다. 논문은 $k\le10^4$인 모든 $k$와 $k\le5\cdot10^4$인 모든
  소수에서 $S(k)$를 계산했습니다.
- **업스트림 형식화.** google-deepmind/formal-conjectures의 커밋
  `c094b979118b89adb77cf5f8d923ac9dd2e51b1d`에 있는
  [`ArithmeticSumS.lean`](upstream/ArithmeticSumS.lean)입니다.
  [upstream/README.md](upstream/README.md)를 보십시오. 그 파일에서 다섯 추측은 모두
  `sorry`로 닫혀 있습니다.
- **문헌 확인(2026-10-24).** arXiv 목록, OpenAlex 전문 검색, 논문의 참고문헌 어디에서도
  논문 자체 외에 $S(k)$를 다룬 연구는 보이지 않았고, OpenAlex에는 이 논문을 인용한 연구가
  없습니다. $S'(h,k)$, $s_3$, $s_4$는 Hardy 합이며 Berndt(1978), Goldberg(1981),
  Berndt와 Goldberg(1984), Sitaramachandrarao(1987)가 연구했습니다. 이 합들의 평균값도
  연구되었는데, 예를 들어 거듭제곱 평균과 Ramanujan 합과의 혼합 평균이 있습니다(Zhang,
  2003; Dağlı, 2020). 그러나 $h$에 대한 단순 합을 계산한 결과는 찾지 못했습니다. 여기서
  사용한 알려진 결과는 다음과 같습니다.
  - Sitaramachandrarao가 $S'(h,k)$를 Dedekind 합으로 나타낸 공식에서 DETAILS의
    Dedekind 형태 (D)가 곧바로 나옵니다.
  - DETAILS 4절의 상호 법칙도 같은 종류의 고전적 결과입니다.
  - Zhang의 $S'(h,k)$ 지표 전개에서 8절의 지표합 표현이 나옵니다.

  Zhang(2003)과 Dağlı(2020)는 직접 읽었지만, 그보다 오래된 논문들은 직접 보지
  않았습니다. 이 논문들에서 인용한 공식은 모두 `verify.py`가 수치로 검사합니다. 정리 7.1이
  쓰는 Dedekind 합의 연분수 공식 (BHK)는 Barkan, Hickerson, Knuth(1977)의 것으로 알려져
  있는데, DETAILS는 그 논문들에 기대지 않고 Dedekind 상호 법칙에서 이 공식을 증명합니다.
- 여기 있는 내용은 저자, formal-conjectures, 그 밖의 어디에도 보고하지 않았습니다.

## Lean 결과

모듈 [`ThetaArithmeticSum.lean`](../../AgenticConjectures/ThetaArithmeticSum.lean),
이름공간 `AgenticConjectures.ThetaArithmeticSum`. `sorry`, 추가 공리, `native_decide`는
쓰지 않습니다. 두 커널 계산은 `decide +kernel`을 사용합니다.

| 선언 | 내용 |
|---|---|
| `S'`, `S` | 업스트림 정의를 항 단위로 그대로 옮긴 것 |
| `statement_1_1`, `statement_4_1` … `statement_4_4` | 다섯 업스트림 추측의 `Prop` 진술(증명하지 않음) |
| `floor_eq` | `S'` 안의 $\mathbb Q$ 바닥 함수 값이 자연수 몫 `h * j / k`와 같음 |
| `S'_eq` | 바닥 함수 대신 그 몫으로 쓴 `S'` |
| `S'_eq_zero_of_odd` | 홀수 소수 `k`와 홀수 `h < k`에 대해 `S' h k = 0` |
| `S'_sub_eq_s4` | 소수 `k`와 `0 < v < k`에 대해 `S' (k - v) k = s4 v k`, 여기서 `s4 v k = ∑_{j=1}^{k-1} (-1)^⌊vj/k⌋` |
| `s4_eq_zero_of_even` | 소수 `k`와 짝수 `0 < v < k`에 대해 `s4 v k = 0` |
| `S_eq_sum_s4`, `S_eq_sum_sq` | 소수 `k`에 대해 `S k = ∑_{v=1}^{k-1} s4 v k = ∑_{a,b=1}^{k-1} (-1)^⌊ab/k⌋` |
| `S_eq_sum_odd` | 소수 `k`에 대해 `S k = ∑_{v<k, v odd} s4 v k` |
| `s4_eq_two_mul` | 홀수 소수 `k`와 홀수 `v < k`에 대해 `s4 v k = 2 ∑_{j=1}^{(k-1)/2} (-1)^⌊vj/k⌋` |
| `S_eq_fastS` | 홀수 소수 `k`에 대해 `S k = fastS k`, 여기서 `fastS`는 구조적 재귀로 계산하는 함수 |
| `small_primes` | $k<300$인 모든 홀수 소수 `k`에 대해 `0 < S k`, `k > 5 → k < S k`, `k > 233 → 2k < S k` |
| `S_fst_10` | 업스트림 테스트 `List.map S (List.range 10) = [0, 0, 1, 2, 5, 4, 7, 10, 11, 8]` |
| `s3`, `H`, `V` | `c * i % v`로 쓴 Hardy 합 $s_3(c,v)=\sum_{i=1}^{v-1}(-1)^i((ci/v))$, 그리고 홀수 $v<k$에 대한 합으로 쓴 $H(k)$와 $V(k)$ |
| `s4_eq_reciprocity` | `k > 0`과 서로소인 홀수 `v`에 대해 `s4 v k = k/v - 1 + 2 s3 (k % v) v`(명제 4.1) |
| `S_eq_exact` | 홀수 소수 `k`에 대해 `S k = k H(k) - (k - 1)/2 + 2 V(k)`(정리 4.3) |
| `statement_1_1_iff` | `statement_1_1 ↔ ∀ k, k.Prime → Odd k → (k - 1)/2 - k H(k) < 2 V(k)` |
| `statement_3_3`, `statement_3_3_lower`, `statement_3_3_upper` | v2/v3의 추측 3.3과 그 두 부등식의 `Prop` 진술(업스트림에 없음, 증명하지 않음) |
| `statement_3_3_iff` | `statement_3_3 ↔ statement_3_3_lower ∧ statement_3_3_upper` |
| `statement_3_3_lower_iff` | `statement_3_3_lower ↔ statement_4_4` |

`small_primes`는 유한한 검사입니다. 추측 4.1과 4.2의 문턱 $5$와 $233$을 포함하지만, 어느
추측도 증명하지 않습니다. `S_eq_exact`와 `statement_1_1_iff`는 모든 홀수 소수에서
성립합니다. 이 둘은 추측 1.1을 $V(k)$의 하계 문제로 바꾸지만, 추측을 증명하지는 않습니다.
`statement_3_3_upper`는 정리 7.1이 손으로 해결한 부등식이며, Lean은 이를 진술만 하고
증명하지는 않습니다.

## 논문의 불일치

- 표 1(v1, v3)은 $k=9$부터 한 칸씩 밀려 있습니다. $9\le k\le20$에서 $S(k)$ 자리에
  $S(k-1)$을 적으므로 $11$이 두 번 나오고 $S(20)=29$는 빠져 있습니다. 예를 들어 표는
  $S(9)=11$, $S(17)=39$로 적지만, 정의에 따르면 $S(9)=8$, $S(17)=24$입니다.
  $S(1),\dots,S(20)$의 올바른 값은 0, 1, 2, 5, 4, 7, 10, 11, 8, 17, 14, 21, 20, 15, 18, 39,
  24, 21, 38, 29입니다. 업스트림 테스트 `S_fst_10`도 정의와 일치하고, 논문 자신의 목록도
  그렇습니다. $17$은 $S(k)<2k$인 소수 목록에 들어 있습니다.
- v3 3절은 소수 $k\le50000$에서 $S(k)>4k$를 위반하는 쌍이 8개라고 하며 그 목록을
  제시합니다. 그 8개는 정확히 $(30000,50000]$에서 $S(k)\le4k$인 소수들입니다.
  $(10^4,5\cdot10^4]$에는 그런 소수가 79개 있고, $5\cdot10^4$ 이하에는 508개의 홀수 소수가
  있습니다. 그 문장은 아마 30000보다 큰 범위를 가리키는 것으로 보입니다.

## 진술의 충실성

- `S'`와 `S`는 $\mathbb Q$ 값 바닥 함수 `⌊(h * j : ℚ) / k⌋₊`까지 포함해 업스트림 파일에서
  항 단위로 그대로 옮겼습니다. `floor_eq`는 이 값이 여기의 모든 프로그램이 쓰는 자연수
  몫과 같음을 증명합니다.
- `Finset.Ico 1 k`는 $\{1,\dots,k-1\}$이므로 논문의 범위 $1\le j,h\le k-1$과 같습니다.
  $k\le1$이면 합이 비어 있어 `S 0 = S 1 = 0`이며, 이 값을 쓰는 진술은 없습니다.
- 각 `statement_*`는 업스트림 `conjecture_*`의 명제와 같으며, 가정 `k.Prime → Odd k → …`와
  `k < S k`, `2 * k < S k`, … 의 `ℕ → ℤ` 형변환도 같습니다. `Odd k`는 논문의 "홀수 소수"와
  마찬가지로 $k=2$를 제외합니다.
- v1은 추측 4.2와 4.3을 "$k>233$에 대해", "$k>3119$에 대해"라고 적습니다. 문맥, v3,
  업스트림은 $k$를 홀수 소수로 둡니다. v3은 추측 1.1을 홀수 소수 $k>5$에 대해 진술하는데,
  $S(3)=2$이고 $S(5)=4$이므로 같은 명제입니다.
- `statement_4_4`는 `∀ n, ∀ᶠ k in atTop, k.Prime → Odd k → n * k < S k`이며, 이는 "$n$에
  따라 정해지는 충분히 큰 모든 소수 $k$에 대해"라는 뜻입니다.
- `statement_3_3`은 업스트림에 대응하는 것이 없으며, 위에 인용한 v3의 문장을 형식화한
  것입니다. 그 내용은 `∀ C₁ C₂ ε : ℝ, 0 < C₁ → 0 < C₂ → 0 < ε → ∀ᶠ k in atTop, k.Prime →
  C₁ * k < S k ∧ S k < C₂ * k ^ (1 + ε)`이며, `k`와 `S k`는 ℝ로 형변환하고 `k ^ (1 + ε)`는
  실수 거듭제곱입니다. "any fixed"는 "모든"으로 읽고, $k$는 원문대로 모든 소수를 돕니다
  ("충분히 큰"이므로 $k=2$는 상관없습니다). `statement_3_3_lower`와 `statement_3_3_upper`는
  같은 한정사를 갖는 두 부등식이며, 각각에서 문턱은 모든 상수에 의존할 수 있습니다.
- `s3 c v`는 톱니 함수 $((ci/v))$를 `(c * i % v)/v - 1/2`로 씁니다. 두 값은 $v\nmid ci$일
  때 같으므로, 여기서 쓰는 유일한 경우인 $\gcd(c,v)=1$이면 합의 모든 $i$에서 같습니다.
  홀수 $k$에 대해 `H k`와 `V k`는 DETAILS의 $H(k)$, $V(k)$와 같습니다. `V`에는 $v=1$ 항도
  있지만 그 값은 $0$입니다.

## 재현

이 디렉터리에서 다음을 실행합니다.

```bash
python3 verify.py
```

이것이 CI 검사입니다(약 15초. `g++`와 `mpmath`가 있는 Python 3가 필요하며, `mpmath`는
CI에서처럼 `sympy`와 함께 설치됩니다). 사용한 모든 항등식을 작은 범위에서 정확하게
검사하고, $k\le400$인 모든 소수에 대해 정리 7.1의 각 단계를 검사하며, 프로그램 A와 B로
$k\le50000$인 모든 홀수 소수의 표를, C로 $k\le2500$인 모든 소수와 $k\le1500$인 모든
$k$의 표를 다시 계산하고, 두 표 전체를 감사합니다(추측, 정리 7.1의 상계, 논문의 목록).

```bash
python3 verify.py --full
```

이 명령은 A와 B를 표 전체에 대해, C를 $k\le30000$인 모든 소수와 $k\le10000$인 모든 $k$에
대해 다시 실행합니다. 몇 시간이 걸립니다.

소수 표를 직접 다시 만들려면 다음을 실행합니다.

```bash
g++ -O3 -std=c++17 s_dedekind.cpp -o s_dedekind && ./s_dedekind 3 2000000 > A.txt
```

방법 B는 `s_hardy.cpp`로 같은 방식으로 실행하고, `s_literal lo hi all`은 한 구간의 모든
$k$를 계산합니다.

## 주장하지 않는 것

- 논문의 어떤 추측도 증명하거나 반증하지 않았습니다. 예외는 추측 3.3의 두 번째
  부등식(정리 7.1)이며, 그 증명은 손으로 쓴 것이고 기계 검증되지 않았습니다. 독립적으로
  검토되었고(별도의 AI 검토 한 번, 빈틈 없음), CI는 그 수치만 다시 검사합니다. Lean은 이
  부등식을(`statement_3_3_upper`) 진술하지만 증명하지는 않습니다.
- 명제 4.1과 정리 4.3(Lean)을 제외하면, DETAILS 3–8절의 항등식도 형식화하지 않았습니다.
  `verify.py`가 작은 범위에서 정확하게 검사하고(명제 8.1은 부동소수점), 방법 A, B, C의
  일치가 계산한 범위 전체에서 이를 검사합니다.
- 계산한 범위 밖에서 계산 결과는 증명이 아니라 증거일 뿐입니다.
