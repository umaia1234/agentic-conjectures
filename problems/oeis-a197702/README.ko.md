# OEIS A197702

[OEIS A197702](https://oeis.org/A197702)은 \(n\)을

\[
n=\pm1\pm3\pm\cdots\pm(2k-1)
\]

로 나타낼 수 있는 최소 양의 정수 \(k\)를 \(a(n)\)으로 정의합니다.
canonical 항목의 추측은 첫 \(k\)개 양의 홀수의 합을 \(SO(k)\)라 할 때,
\(SO(k-1)<n\le SO(k)\)인 위쪽 제곱 지수 \(k\)와 차이
\(d=SO(k)-n\)에 따라 \(a(n)\)을 세 경우로 분류합니다. 정확한 영문
원문과 리비전 정보는 [로컬 명제 스냅샷](upstream/A197702.txt)에
보존했습니다.

## 결과

공식 offset의 모든 \(n\ge1\)에 대해 이 추측이 성립합니다. 첫 \(k\)개
홀수의 합은 \(k^2\)이므로

\[
(k-1)^2<n\le k^2,\qquad d=k^2-n
\]

로 두면

\[
a(n)=
\begin{cases}
k+2,&d=4,\\
k+1,&d\text{가 홀수},\\
k,&\text{그 밖의 경우}
\end{cases}
\]

입니다. 이는 유한 범위 검사가 아니라 무한 전칭 명제 전체의 증명입니다.

## 증명 아이디어

마이너스 부호를 준 위치의 집합을 \(S\)라 하면 부호합 조건은 정확히

\[
n+2\sum_{i\in S}(2i+1)=k^2 \tag{1}
\]

과 동치입니다.

핵심 보조정리는 \(0<t<2k+1\)인 정수 가운데 \(t=2\)만 제외하면 모두
\(\{1,3,\ldots,2k-1\}\)의 서로 다른 원소들의 합이라는 것입니다.
\(t\)가 홀수이면 \(t\) 하나를 택하고, \(t\)가 2가 아닌 짝수이면
\(1+(t-1)\)을 택합니다. 반대로 서로 다른 양의 홀수들의 합은 2가 될 수
없습니다.

따라서 짝수 차이 \(d\ne0,4\)는 길이 \(k\)에서 \(d/2\)를 부분합으로
택하면 되고, \(d=0\)에서는 마이너스 부호가 필요 없습니다. 홀수 차이는
길이 \(k\)에서 parity 때문에 불가능하지만 길이 \(k+1\)에서 핵심
보조정리로 구성됩니다. \(d=4\)일 때 길이 \(k\)는 불가능한 부분합 2를
요구하고 길이 \(k+1\)은 parity가 맞지 않지만, 길이 \(k+2\)에서는
\(1+(2k+3)=2k+4\)로 구성됩니다.

또한 \(j<k\)이면 처음 \(j\)개 홀수의 어떤 부호합도
\(j^2\le(k-1)^2<n\)을 넘지 못하므로 더 작은 길이는 불가능합니다.
[DETAILS.ko.md](DETAILS.ko.md)에 전체 논증을 적었습니다.

## Lean 형식 증명

[`AgenticConjectures/OeisA197702.lean`](../../AgenticConjectures/OeisA197702.lean)은
실제 부호 선택 술어 `SignedSum`을 정의하고, 이를 자연수 부분집합 식과
동치임을 증명한 뒤 예상 길이가 정확히 최소라는 `IsLeast` 정리를
증명합니다. 최종 등록 정리는 다음 내용을 담습니다.

```text
oeis_a197702 :
  ∀ n k, 0 < k → (k - 1) * (k - 1) < n → n ≤ k * k →
    a n = if k * k - n = 4 then k + 2
      else if Odd (k * k - n) then k + 1 else k
```

`sorry`, 추가 공리, `native_decide`를 사용하지 않습니다.

## 명제 충실성

- `SignedSum n k`는 첫 \(k\)개 홀수 각각에 실제로 \(+1\) 또는 \(-1\)
  부호를 배정합니다. `signedSum_iff_representable`이 이것과 (1)의 정확한
  동치를 증명합니다.
- `a n`은 조건을 만족하는 양의 길이들의 하한으로 정의됩니다. 증명에서
  실제 후보를 구성하고 최소성을 보이므로 하한은 실제 최소값입니다.
- 구간 가정은 OEIS의 \(n=SO(k)=k^2\)인 경우와
  \(SO(k-1)<n<SO(k)\)인 경우를 모두 그대로 포함합니다.
- 공식 offset은 1이며 구간 가정에서 \(n>0\)이 따라옵니다. 인위적인
  \(n=0\) 항은 주장하지 않습니다.
- 자연수 뺄셈 \(k^2-n\)은 명시적 가정 \(n\le k^2\) 아래에서만
  사용하므로 보통의 음이 아닌 차이와 같습니다.
