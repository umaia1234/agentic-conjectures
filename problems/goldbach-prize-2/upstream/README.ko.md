# 원문 스냅숏 메타데이터

- 공식 페이지: <https://www.dimostriamogoldbach.it/en/prizes/>

원문은 정수 \(1<n_1<n_2<n_3\)을 고정하고
\(\mathrm{t\_space}_{(n_1,n_2,n_3)}(x)\)를 세 법 어느 것으로도 나누어지지
않는 \(x\)번째 양의 정수로 정의한다. 그리고 모든 \(x>0\)에 대해 다음을
만족하는 \(f:\mathbb N^\star\to\mathbb N\)을 요구한다.

\[
 f(x)-\frac{n_3^2}{2}
 \leq \mathrm{t\_space}_{(n_1,n_2,n_3)}(x)
 \leq f(x)+\frac{n_3^2}{2}.
\]

페이지는 \(f\)의 공식에 합, 차, 곱, 나눗셈, 유한한 수의 경우 구분을
사용할 수 있다고 하고, 표시된 모든 매개변수와 양의 지표에 대해 성립하는
증명을 요구한다.

핵심 원문은 다음과 같다.

> “includes only operators of sum, difference, product, division and
> distinction between a finite number of cases.”

`Solution under review`로의 행정 상태 변경은 승인이나 상금 지급을 기록한
것이 아니다. 페이지에 제출 문서나 제출자의 신원이 없으므로, 이 스냅숏은
그 검토를 특정인이나 이 저장소와 연결하지 않는다. 이 파일은 명제 충실성
대조에 사용한 웹 문구를 기록하며, 공식 페이지가 최종 원문이다.
